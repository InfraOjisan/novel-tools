# AGENTS.md — 司令塔（Claude）の手順書（Novel_4・星型チーム）

## 最上位の約束
1. 物語の中身（本文・設定・採点）を司令塔が自分で書かない。書くのはワーカー、決めるのは機械検査と人。
2. 状態はディスクだけ。迷ったら `python3 tools/team.py status`。
3. `STOP` ファイルが直下にあれば、すべて止まる。人が置く。
4. 承認・公開・seal は人の仕事（`approve-canon` は人が確認した指紋で）。ESCALATE が出たら自分で直さず人に報告する。
5. `runs/team/` と `runs/aion/` は互いに読まない。CANON だけが共通。

## 構成（星型）
司令塔 → ワーカー（毎回まっさらな1回きりのAPI呼び出し。道具・メモリ・ファイルアクセスなし）
- 設計役 / 執筆役×3（別系統） / 編集役（匿名で比べる） / 検査役（別系統・引用つき・機械照合） / 台帳役（事実は引用つき） / 審査役
- 機械：字数・形式・禁止の言葉・管理用語・既存文章との30字一致・CANON指紋

## 手順
1. `canon` → 人が読む → `approve-canon --sha 先頭8字`
2. 章ごとに `write N --mode team` と `write N --mode aion`（長いので `nohup ... &` で走らせ、`status` と `runs/<mode>/logs/run.jsonl` で見る）
3. `judge N`（名前を伏せた比較。引用は機械照合）
4. 結果は `notes/` に残す。
