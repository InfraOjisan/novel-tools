# 校正の記録 —『祝福の日』（2026-10-24）

プロデューサーの通読（通読用初稿 EPUB）の指摘を反映。機械の点検（句読点の重複・空の括弧・半角英数字）は「A」（札の署名）と章番号のほかに該当なし。

| 章 | 指摘 | 直し |
|---|---|---|
| 1 | 「昨日まではいなかった顔」が誰のことか曖昧。ヴィルマは十日目なので誤り | ダリオが護送で弥生の半ばから街を空けていた、だからこの顔を見るのは初めて、に直した。ダリオがカウンターの端の席を立つ、と書き足した |
| 5 | マスターが組合の受付をしているように読める | ブリギッテは組合長の在否を訊く形に。「登録簿をつけるのは、組合長の仕事だ。俺は酒を注ぐだけで、組合の帳面には触らない」を足した |
| 5 | 下町で施療をしていたなら、エルノを知っていてもおかしくない（種） | ブリギッテ「去年の秋まで、白い法衣の方をよく見かけました。…霜月から、見かけなくなりました」、マスター「遠くへ行かれたそうです」を足した（嘘はない） |
| 5 | ダリオの居場所が章内で動く | ダリオはカウンターの端。フィンが来たときに、杯を持ってリナの卓へ移る、と書いた |
| 9・13 | ダリオはカウンターの端 | そのまま（ダリオの定位置。第14章で樽の脇へ椅子をずらすのは、栓が抜かれる前ぶれ） |

プロデューサー講評：種は多すぎることはない（読者は種を意識して読まない）。意識するのは芽吹きと回収の数だけでよい。
