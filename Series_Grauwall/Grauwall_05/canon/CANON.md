## 0. タイトルと要旨
- タイトル：隊長の非番
- 要旨（あらすじ用。長い糸を使わない）：灰壁暦三一三年、如月。治安維持隊長マグダが、私服で錆び釘亭に飲みに来た。外套に留め金がない。若い隊員に頬の傷のことを訊かれて、隊長は「転んだ」と答える。転んで、耳の下から口の端まで切れる者はいない。非番は休みではなかった。令状のない家探しを断った隊長に、参事会は監査と謹慎で返した。監査役は三十年分の帳面をさかのぼり、二十三年前の朝の一行に近づいていく。帳面は破らない帳場の老人と、真実を一つ選ぶことを覚える若者と、予算で飯を食う隊長の、九日間。

## 1. 舞台（SERIES_BIBLE からの抜粋）

### 1-1. 街・暦・鐘・城門・通貨と物価
- 城塞都市グラウヴァル。上町（丘・白漆喰の屋敷・ロズモンド館・市参事会館・穀物商の倉）、大聖堂と中央広場（治安維持隊詰所）、下町（酒場・賭場「黒猫の尾」・宿・冒険者組合／錆び釘亭）、下の谷（亜人街）。北門は追放の門、南門は交易の門。
- 灰壁暦。本作は三一三年 如月十日〜十七日と、二十五日（隊の給金の日）の夜。雪は残るが、日中は軒から水が落ちる。春の議は弥生十日。
- 大聖堂の鐘が一刻ごとに刻の数だけ鳴る。半刻には一打。夜半と昼はそれぞれ十二打（昼の鐘）。夕方六つで城門が閉まり、朝六つで開く。夕べの祈りは六つの鐘。黒猫の尾は七つまで戸を開けない。
- 金貨一枚＝銀貨二十枚＝銅貨四百枚（銀貨一枚＝銅貨二十枚）。
- 物価：赤蕪漬けの鶉卵 一個銅貨二枚／麦酒一杯 銅貨五枚／蒸留酒一杯 銅貨十二枚／煮込み一皿 銅貨十枚／下町の宿一泊 銀貨一枚／荷運びの駄賃（半日）銀貨三枚。参事会から組合への助成 年に金貨百二十枚（春の議で打ち切りが議される）。

### 1-2. 嘘の作法（本文で読者に示す形）
| 誰 | 嘘をつけるか |
|---|---|
| 亜人（灰狼族・蜥蜴人・兎人族・鴉人・土竜人） | 嘘をつけない（月影の戒め）。黙る・はぐらかす・問いで返すことはできる。例外はない |
| 灯火教会の聖職者 | 嘘をつかない（誓願）。例外はない |
| 組合の剣士・盗賊・魔法使い・賢者 | 組合の建物の中では、仲間に嘘をつかない（鉄の誓約）。例外は三つ（長の命・代価・酒精）。例外は鉄の誓約にだけ効く |
| 組合長 | 誓約の主。嘘をつける |
| 組合に属さない人間 | 普通に嘘をつける（マスター、治安維持隊、帳場、参事、番頭、見習い騎士など） |
- 嘘とは、本人が偽りと知っていることを言うこと。マグダの「転んだ」は嘘。オスカーの『訓練中の事故』は帳面の上の嘘。トマスの「訓練中の事故って、書いてあるっす」は嘘ではない（書いてある）。
- 人間の多くは、同じ種族の亜人を一人一人見分けない。亜人同士は見分ける。

### 1-3. 組合と錆び釘亭（三一三年 如月）
- 間取りは第2回のとおり（表の扉の内側に樽の箍の擦り傷、梁の焦げ一か所）。階段の下の物置に帳簿箱。二階に組合長の部屋（酒場の真上。床板が薄い）と書庫、廊下の奥にマスターの寝床と空き部屋（ルルが使っていた）。中庭に井戸と厩。厩の二階で雑役が寝起きする（厩の中の狭い階段で上がる）。寝床はザザがいちばん奥の藁、ドゥンが窓の下、ヴェイ（夜番の夜）が戸の脇、コルは梁の上。
- 雑役の亜人は四人：ザザ（掃除番。厩の二階のいちばん奥の藁）、ヴェイ（下の谷から通い。荷運びと夜番）、コル（鴉人の伝令。厩の梁で寝る。昼は治安維持隊の伝令も日雇いで走る）、ドゥン（土竜人。井戸の手入れ）。
- 組合長エーリカ・ランゲ。右の膝を痛めている。迷う夜は部屋を歩く（窓から扉まで七歩）。
- 赤い卵の瓶：毎朝十二個漬ける。鶉の卵はトマスの母の鶉小屋から。マスターは底の一つをよける（この回は第5章で一度だけ書く）。
- 第2回の祝いの樽（南の葡萄酒の中樽）：栓は春の議のあとまで抜かない。マグダは春の議のあとに一杯もらいに来ると言っている（「三人へ」の贈り物なので自分の分であり、掟の二つ目の只酒には当たらない、というのがマグダの言い分）。
- 裏口のスープ：毎晩。ハクとチィが来る。
- 六つから七つ半は客がいない。

### 1-4. これまでの状態（台帳と第4回より）
- 三一二年 霜月：前組合長バルタザールが紅玉の盗みを仕組んだ罪で連行され、詰所の牢にいる（裁きは春の議のあと）。姪のイゾルデ、盗賊ニコ、賢者エルノも連行された。財産は差し押さえ。
- 三一二年 霜月二十一日：エーリカが組合長に着任。参事会の内示を退けた。助成の打ち切りは春の議へ。
- 三一二年 師走：北街道の依頼に隊員フィンが同行し、戻った（第3回）。北門の番はトマスだった。
- 三〇九年の冬（第4回）：参事会が七対五で『城内亜人の頭数改め』を通した。改め役は番頭カスパルと書記ヨーナス、護衛は隊長マグダ（マグダは問答の場にはおらず、中庭にいた）。錆び釘亭の兎の衣装の給仕は『錆び釘亭　給仕　一』と記帳された。同じ冬の睦月四日の夜半すぎ、バルタザールが厩の階段を上り下りし、給仕が「組合長さんは、夜に藁の中で何を数えてるの？」と言った。マスターは厩へ行かなかった。
- 三一二年 霜月（第一作）：隊が厩の二階を改め、灰色たちの寝藁を階段から放り出した。奥のトカゲの隅は誰も見なかった。

## 2. 事件の仕組み（物語の論理）

### 2-1. 治安維持隊の形（第2〜3章でトマスとマグダの口から）
- 詰所は中央広場。灰色の外套、革の胸当て、鉄を打った靴。棍棒と短い槍。
- 人数：

| 役 | 人数 | 月の給金 | 年の額 |
|---|---|---|---|
| 隊長（マグダ） | 一 | 金貨五枚 | 金貨六十枚 |
| 副長（北門番の頭・南門番の頭） | 二 | 金貨三枚 | 金貨七十二枚 |
| 隊員（十五人の班が四つ。北門の班、南門の班、町廻りの班が二つ） | 六十 | 銀貨三十枚 | 金貨千八十枚 |
| 帳場（オスカー） | 一 | 金貨二枚 | 金貨二十四枚 |
| 帳場の見習い | 一（秋から空き。いまはトマスが隊員の給金のまま回されている） | 銀貨十枚 | 金貨六枚 |
| 牢番 | 二 | 銀貨三十枚 | 金貨三十六枚 |
| 給金の計 | | | **金貨千二百七十八枚** |

- 隊員の給金は、日雇いの荷運び（半日で銀貨三枚）より少ない。そのかわり、詰所の賄い（朝と夕）、独り者は詰所の二階の寝床、外套・靴・槍・胸当ての支給がつき、雪の月も病の月も同じ額が出る。勤めの最中に死ねば、家に扶持が出る。ダリオの冷やかし「日雇いのほうが稼げるぜ」に、マグダ「日雇いは、死んだら終わりだ」。

- 年の予算（参事会から）：**金貨千八百枚**。

| 行 | 年の額 |
|---|---|
| 給金 | 金貨千二百七十八枚 |
| 装備と修繕（槍、靴、外套、胸当て） | 金貨百八十枚 |
| 灯油と薪（詰所と門の番小屋） | 金貨百十枚 |
| 牢の食い扶持 | 金貨七十枚 |
| 遺族扶持（在職中に死んだ隊員の家、十四家に月銀貨十枚ずつ） | 金貨八十四枚 |
| 雑費（亜人の日雇い：鴉人の伝令、灰狼の跡追い。走り一回銅貨十枚、跡追い半日銀貨二枚） | 金貨四十八枚 |
| 予備 | 金貨三十枚 |
| 計 | **金貨千八百枚** |

- ブラントの削り案（参事会勘定方。春の議に出す）：一割、金貨百八十枚を削る。**はじめの案**＝遺族扶持八十四枚をすべて、雑費四十八枚をすべて、灯油と薪から四十八枚。**出し直しの案**（第11章）＝雑費四十八枚をすべて、灯油と薪から四十八枚、装備と修繕から八十四枚。遺族扶持は残る。
- 隊員の給金の日は毎月二十五日（第2回の本文どおり）。
- 字が読めて算盤も弾ける隊員は五人ほど（マグダ、副長二人、フィン、トマス）。副長は門を離れられず、フィンは町廻りの班の頭役なので、いちばん若いトマスが帳場に回された。
- **亜人は隊員になれない**：参事会の定め『隊員は城壁の内に生まれた人間に限る』。ただし雑費の行で、鴉人の伝令（コルもその一人）と灰狼の跡追いを日雇いで使う。帳面の上では「人」ではなく「費え」として書かれる（『走り　十回　銅貨百枚』）。

### 2-2. 隊の掟八箇条（詰所の壁の板。第3章でトマスが諳んじる。一字一句）
> 『一、上役の得物に手をかけた者は、隊を出す。
> 　一、賭場と酒場で只酒を飲んだ者は、隊を出す。
> 　一、参事会の議決か令状なくして、家の戸を開けさせない。
> 　一、夜の門は、隊長の命でも開けない。
> 　一、非番の者は、刃を帯びない。
> 　一、心付けは、銅貨二枚まで。
> 　一、掟を拒む亜人には、要るだけの力を用いる。
> 　一、帳面は、破らない。』
- マグダの皮肉（第3章）：二つ目に「だから私は、今日は金を払って飲んでる」。六つ目に「銅貨二枚。卵一つまでだ。隊ではそう言う」。四つ目に「隊長の命でも開けない門を、隊長が開けろと言ったら、開けなかった奴を褒める」。五つ目に「刃は帯びてない。棍棒も置いてきた。今日の私は、ただの背の高い女だ」。七つ目には何も言わない。
- 八つ目はオスカーが先代の隊長に頼んで足した。
- 令状：参事会の裁き役が出す。訴え人の名と、探す物の名を書かねばならない。差し押さえ漏れの訴えなら、訴え人は差し押さえの債権者か、差し押さえを受けた本人。参事会の議決は春の議まで開かれない（臨時の議には、参事の過半が名を連ねる求めが要る）。

### 2-3. 非番の理由（第4章でフィンの口から）
- 如月七日、参事ブラントが詰所に来て、マグダに命じた。「前組合長の差し押さえ漏れの財産が、組合の建物に隠されているとの訴えがある。今日のうちに改めよ」。令状はない。マグダ「令状か議決を持ってきてくれ。掟の三つ目だ」。
- 如月八日の朝、参事会勘定方の名で監査が入る。監査役はブラントの番頭カスパル。隊長は「監査が済むまで、春の議まで、詰所に入るな」と言われる（謹慎。表向きは非番）。副長の一人（北門番の頭）が隊長の代わりをする。
- 監査役カスパルは、隊の見舞金の綴りを三十年分さかのぼっている（「不正な見舞金があれば、隊長の監督の咎」）。八日に三一三年から始め、はじめは一日に三年ほど進む。古い綴りほど字が薄く紙が脆いので遅くなる。十四日の夜に二九五年、十五日に二九二年、十六日に二九一年、**十七日の朝に二九〇年**に届く。

### 2-4. 二九〇年の帳面と日誌（第7章で写しを見せる。一字一句）

### 2-5. 二十三年前の朝（第10章でマグダが語る）
- 灰壁暦二九〇年 弥生十二日、朝六つ。北門。雪が残っていた。
- 上町の屋敷で銀の杯が一つなくなり、洗い物をしていた灰狼の洗濯女が「関わった」として、灰壁の掟で追放される。罪は量られない。
- 洗濯女の子（小さかった。八つくらい）が、母の外套の裾をつかんで離れない。谷の者が引き離そうとするが、子は離さない。
- 班長ヴォルフ・ハーゲン（当時三十代。大柄。隊でいちばん槍が上手かった）が言う。「離れんなら、離させる」。短い槍を逆さに持ち、柄で子の腕を打とうと、頭の上に振りかぶる。穂先は上、後ろ。
- マグダ（二十三。隊に入って四年。隊でいちばん背が高かった）は、ハーゲンの斜め後ろにいた。ほかの者はハーゲンの腕にしか届かない。マグダだけが、頭の上の柄に手が届いた。柄をつかむ。ハーゲンが振りほどこうと引く。槍が回る。穂先が、マグダの左の耳の下から口の端へ滑る。
- ハーゲンは槍を取られて、雪の上に尻餅をつく。子は母から離され、谷の者に抱えられる。母は北門を出る。
- 門の内で、追放の朝に黒パンを渡しに来ていた灯火教会の修道女（四十ほどのアガタ）が、灯の術で傷を閉じる。痕が残る。アガタは何も訊かなかった。
- 掟の一つ目（上役の得物に手をかけた者は、隊を出す）。帳場のオスカー（四十前）が『訓練中の事故』と書き、見舞金銀貨十枚を出した。ハーゲンが連署した。
- ハーゲンは二九七年に隊長になり、三〇五年、隠居するときにマグダを跡目に推した。三〇八年、胸の病で死んだ。
- マグダが覚えていること：母の外套の色（煤けた緑）、子の手が小さかったこと、雪。覚えていないこと：子の顔（灰狼の子を見分けなかった）。
- マグダの台詞（一字一句）：「届いたのは、私だけだった。背が高かったからだ」「子どもの顔は、覚えていない。手が、小さかった」「転んだのは、ハーゲンのほうだ。槍を取られて、尻餅をついた」。
- **戦いでも事故でもない**。止めようとした者が、届いたから負った傷。

### 2-7. 解決の筋道
1. 第5章：ブラントが「姪に書かせてな」と口を滑らせる（彼は帳面を恐れている）。
2. 第6章：マスターが三〇九年の夜を思い出す。マグダが、ブラントが牢のバルタザールに二度会いに行ったと言う。
3. 第9章：マスターがザザに寝床の下のことを一つだけ訊く。裏帳面が出る。
4. 第11章：マスターがエーリカに渡す。エーリカは一行を写して封をし、コルに持たせる。包みはザザの寝床の下に戻す。
5. 第11章：同じ日の昼、監査役がトマスに訊く。トマスは真実を一つ選んで答え、刻を稼ぐ。昼の鐘のあと、参事会の使いが詰所に来て監査は取り下げ（表向き「帳場の写しに足りぬところがあり、出し直させる」）。隊長の謹慎は解ける。削り案は出し直し。
6. 第12章（二十五日、給金の日）：マグダが外套で来る。

### 2-8. 嘘の作法との照合
- マグダ：「転んだ」は嘘（組合の外。つける）。ほかでは嘘をつかない。
- オスカー：帳面の『訓練中の事故』は二十三年前の嘘。この回では嘘をつかない。
- トマス：嘘をつかない（「書いてあるっす」「北門の棚っす」はどちらも事実）。
- エーリカ：嘘をつかない（ブラントへの断りも事実だけ）。
- ザザ、コル、ヴェイ、ドゥン、アガタ：嘘をつかない。ザザは訊かれたことに字義どおり答える。
- マスター：この回では嘘をつかない（エーリカに「組合の建物で見つかった組合の物です」は事実）。
- 新しい例外を足さない。

## 4. 人物

### マスター（語り手「俺」）
- 人間、五十を少し越えた。錆び釘亭の雇われ酒場番。十年前に組合を抜けた元斥候。地の文は「俺」、台詞は丁寧（「私」「〜ですね」「さて」）。部屋に入ると人数と出口を数える。三人の女を数えないことにしている。
- この回で、ザザに寝床の下のことを一つだけ訊く。ザザが見たこと（誰が、いつ）、瓶、靴は訊かない。裏帳面を自分の手札にしない。理由は書かない。

### マグダ（治安維持隊長）
- 人間、四十六。背が高い（店の梁に頭が近い。戸口で少しかがむ）。左の頬に、耳の下から口の端まで古い刃物の傷。笑うと傷が引きつれて、片側だけで笑う。
- 私服：古い茶の外套（留め金がなく、紐で結ぶ）、灰色の毛糸の襟巻き、革の長靴（鉄を打っていない）。刃も棍棒も持たない。
- 口癖「予算で飯を食ってる」「掟は掟だ」。
- 話し方：短い。男言葉寄り。一人称「私」。
- 傷のことを訊かれたら「転んだ」。三度目まで。第10章で本当のことを言う。
- 二十三年前のことを、恥とも誇りとも言わない。
- 監査を誰が止めたかを訊かない。天井を一度見上げる（エーリカの部屋）。

### トマス（若い隊員）
- 人間、十九。頬に産毛。北門の班から帳場の手伝いに回された。
- 父ハンスは隊員で、九年前（三〇四年）、在職中に熱病で死んだ。母は遺族扶持（月に銀貨十枚）と鶉小屋で暮らす。錆び釘亭の卵は母の鶉の卵。
- 給金の日（二十五日）に銅貨二枚を持ってきて卵を一つ買う。
- 悪気なくしゃべる。「〜っす」。手習い所でアガタに字を習った。隊で字が読めて算盤も弾ける五人ほどのうちの一人。
- 監査役の問いに：「訓練中の事故って、書いてあるっす」「門番日誌は、北門の棚っす」。

### オスカー（帳場・新登場）
- 人間、六十二。隊の帳場に三十一年（二八二年から）。剣を持ったことがない。痩せて背が丸い。眼鏡を額に上げたまま眼鏡を探す。指にインクの染み。算盤の玉を親指で弾く癖。
- 一人称「わし」。マグダを「隊長」。一度だけ「マグダ」（第8章）。トマスを「小僧」。マスターを「酒場番さん」。
- 口癖「帳面は、破らない」。
- 二十年ぶりに錆び釘亭に来る（若いころ、ハーゲンに連れられて何度か来た）。

### ヴォルフ・ハーゲン（故人）
- 二九〇年に班長（三十代、大柄、隊でいちばん槍が上手い）。二九七年に隊長。三〇五年に隠居し、マグダを跡目に推した。三〇八年、胸の病で死んだ。本文では話の中にだけ出る。

### エーリカ・ランゲ（組合長）
- 第2回のとおり。四十代半ば。右の膝を痛めている。灰色がかった栗色の髪を首の後ろで一本に編む。丁寧で少し硬い（「わたし」）。迷う夜は部屋を歩く。
- ブラントに：「令状か、参事会の議決をお持ちでしたら、すぐにご案内します」「忘れておりません」。
- 裏帳面を読み、一行を写し、組合の釘の封蝋で封をする。コルに「ブラント参事に。返事は要らない」。ザザに「もう少し、その上で寝てくれる？」。何を写したかを誰にも言わない。

### ゲルハルト・ブラント（参事）
- 人間、五十代の終わり。上町の穀物商。参事会の勘定方。亜人排除派の旗頭。痩せて背が高い。灰色の毛皮の襟。声が低く、数字をゆっくり言う。
- 組合で：エーリカに「前の組合長の部屋を、見せてもらえまいか」。断られて「組合の助成は、春の議にかかっていることをお忘れなく」。去りぎわにマスターへ「前の組合長は、帳面の几帳面な男だった。姪に書かせてな」。
- 牢のバルタザールに二度会いに行った（差し入れは持たずに）。

### 脇の人物
- **ザザ**：老いた蜥蜴人の掃除番。熱が見え、人を足で覚える。字義どおりにしか話さず、訊かれたことしか言わない。一人称「私」。寒い夜は体が遅い。厩の二階のいちばん奥の藁で寝る。台詞（一字一句）：「ある。私は、その上で三年寝ている」「どけと言われれば、どく」「持っていくのか」「返すのか」「寝る」。誰が置いたか、なぜ言わなかったかは、訊かれないので言わない。
- **ダリオ**：人間の剣士、三十代の大男。髭の端が縮れている。酒好きで、情に厚い。懐はいつも寒い。黒猫の尾で見習い騎士に賭け札で勝った。
- **コル**：鴉人の若者。組合の伝令。厩の梁の上で寝る。昼は治安維持隊の伝令も日雇いで走る（一回銅貨十枚）。嘘をつけないので伝言を一字も盛らない。噂も速い。
- **ヴェイ**：灰狼族。下の谷から通い。この回では裏口のスープと夜番に出るだけ。マグダと同じ場面に置いてもよいが、二人のあいだに何も起こさない。
- **フィン**：治安維持隊の隊員、二十代。町廻りの班の頭役。第3回で北へ行った「隊の若いの」。真面目。字が書ける（第3回で手帳に書いていた）。隊長を慕っている。北街道の話はしない。
- **アガタ**：灯火教会の修道女、六十代。白い手袋。嘘をつかない。訊かないことにかけては亜人より上手。月に一度の施療。この回では第8章に一場面。マグダに「冷える日は、痛みますか」。マグダ「予算ほどじゃない」。
- **カスパル**：ブラントの番頭。四十代の終わり。参事会勘定方の名で隊の監査役。指で数える。笑わない。三年前の頭数改めの問う役（本人はそのことを言わない）。
- **ヨアヒム**：上町の見習い騎士、十八。黒猫の尾でダリオに賭け札で負け、札の貸しを払わずに「いかさまだ」と言う。錆び釘亭で剣の柄に手をかける。
- **ハクとチィ**：ヴェイの子。裏口のスープ。

## 6. シリーズの長い糸（置き方は BRIEF 第1-B節）
- **S1（瓶の底）**：第5章で一度だけ。マグダが卵を一つ。マスターは底の一つをよける。意味づけしない。
- **S2（マグダの見立て）**：第7章で一度だけ。三〇九年の記帳を見て笑ったあと「酒場番。果物は、まだ剥いてるか」。マスター「林檎の季節ではありませんが」。それ以上は書かない。
- **S5（助成と春の議）**：第11章。動作一つ。エーリカが包みをザザの寝床の下へ戻す。手札とも春の議とも書かない。
- 二話越しの回収：Z1（寝床の下）、Y1（三〇九年の記帳）。
- 動かさない糸：S3（ザザに訊くのは寝床の下に物があるかだけ。ザザが見たこと、瓶、靴、三年前の秋のことは訊かない。シリーズの「誰かがザザに正しい問いをする」山場は手つかずで残す）、S4、S6〜S13。紅玉の在りか、北街道、亡骸、白いカフス、赤い棘草に触れない。夫人を出さない。
- 『石の件』の一行（第9章）と三〇九年の記帳のルル（第7章）は、この話の筋として地の文で一行ずつに留める。

## 7. 伏線スロット

- **T1（「転んだ」）**
  - 設置（第1章）：トマス「その傷、どうしたんすか」マグダ「転んだ」。地の文：転んで、耳の下から口の端まで切れる者はいない。
  - 補強（第7章）：二九〇年の写しを前に、トマスがもう一度訊く。マグダ「転んだ」（二度目。声は同じ）。
  - 回収（第10章）：「転んだのは、ハーゲンのほうだ。槍を取られて、尻餅をついた」。
- **M1（留め金）**
  - 設置（第1章）：茶の外套に留め金がない。紐で結んでいる。マスター（地の文）：役を脱ぐ合図を持たない隊長は、初めて見た。マグダは紐をほどかない。
  - 補強（第10章）：話し終えたマグダが、外套の紐を一度ほどき、結び直す。
  - 回収（第12章）：灰色の外套。留め金は二つとも留まっている。カウンターに座り、上の一つを外す。
- **O1（帳面は破らない）**
  - 設置（第2章）：トマスが帳場のオスカー爺さんの口癖として言う。
  - 補強（第8章）：オスカー「頁を破れば済む。だが、帳面は破らない。わしが書いた。それ以上は、隊長が言うことだ」。マグダ「破るな、オスカー。掟は掟だ」。
  - 回収（第11章）：トマスが監査役に、帳面に書いてあることだけを言う。
- **K1（掟八箇条）**
  - 設置（第3章）：全文。マグダの皮肉。
  - 補強（第4章）：三つ目（令状）が非番の理由。
  - 補強（第8章）：一つ目（上役の得物）が危うさ。
  - 回収（第10章）：七つ目（要るだけの力）と一つ目が二九〇年の朝でぶつかる。（第11章）三つ目と八つ目が守られたまま、監査が止まる。（第12章）六つ目の冗談（銅貨二枚）。
- **G1（顔代の帳面）**
  - 設置（第5章）：ブラント「前の組合長は、帳面の几帳面な男だった。姪に書かせてな」。
  - 補強（第6章）：マスターの回想。マグダ「ブラントは二度、牢のバルタザールに会いに来た。差し入れは持ってこなかった」。
  - 回収（第9章）：裏帳面の中身。（第11章）エーリカの一行。
- **Z1（寝床の下）**
  - 補強（第6章）：回想。「あら、組合長さんは、夜に藁の中で何を数えてるの？」。
  - 回収（第9章）：「ザザ。お前の寝床の下に、何かあるか」「ある。私は、その上で三年寝ている」。マスターはそれ以上訊かない。
- **Y1（三〇九年の記帳）**
  - 回収（第7章）：『錆び釘亭　給仕　一』とマグダの判。マグダ「私の判で、兎が人間になってる」。マスターは杯を拭く。

## 8. 結末
- 監査は取り下げられ、隊長は詰所に戻る。誰も帳面を破らない。誰も裏帳面を表に出さない。
- 遺族扶持は残る。雑費の行は春から消える。コルの走り賃も。
- ブラントは議席に座ったまま。エーリカの手札は藁の下。春の議で助成の打ち切りは続く（S5）。
- 二十三年前の朝を、トマスとマスターが知った。
- 最後の場面：給金の日の夜。マグダが上の留め金を外す。銅貨二枚が梁の上へ。
- 最後の一文：マスターの乾いた一文。留め金か、銅貨か、天井のどれかに触れる。説明や教訓で締めない。

## 9. 不変条件
1. 語り手はマスターの「俺」だけ。地の文は嘘をつかない。
2. 亜人（ザザ、コル、ヴェイ、ドゥン、ハク、チィ）と聖職者（アガタ）は一度も嘘をつかない。
3. マグダが嘘をつくのは「転んだ」だけ（第1章、第7章）。
4. トマス、オスカー、エーリカ、マスターはこの回で嘘をつかない。
5. 隊の人数・給金・予算・削り案・掟の文面は第2節のとおり一字一句変えない。帳面・日誌・記帳の文面も同じ。
6. 二九〇年の朝は第2-5節のとおり。子の名・種族の個体を書かない。子は傷つかない。
7. 赤い卵の瓶の底の一つをよける所作は第5章で一度だけ。意味づけしない。ほかの章で瓶が出るときは、底に触れない。
8. マグダはマスターを量らない。S2は第7章の一言だけ。マグダの見立てを明かさない。
9. ザザに訊くのは「寝床の下に何かあるか」の一問だけ。ザザが見たこと、誰が置いたか、瓶、靴は訊かない。章題・あらすじに「問い」の語を使わない。
9-2. 厩の二階へは階段。給金の日は二十五日。
10. ルルが死んだと書かない。北街道、亡骸、白いカフス、紅玉の在りかに触れない。『石の件』は第一作の盗みとして一行で受ける。
11. 夫人を店に来させない。祝いの樽の栓を抜かない。
12. エーリカが写した行を本文に書かない。
13. ブラントを失脚させない。差別を解決しない。
14. 第4回を読んでいない読者が、第6章の回想だけで寝床の下の話についてこられること。
15. **審査項目**：長い糸を何も知らない読者が、この話の入口（私服の隊長と「転んだ」）と結末（留め金と銅貨二枚）だけで満足できるか。

## 10. 文体
- 声：マスターの「俺」。ややハードボイルド。短い文、乾いた比喩。酒場と帳場の具体物（杯、樽、卵の瓶、算盤の玉、羽根ペン、帳面の背、綴じ紐、油の灯、硬貨、黒板、雪解けの軒の水）。
- 台詞：マスターは丁寧。マグダは短く崩す。トマスは「〜っす」。オスカーは「わし」で古い言い回し。エーリカは丁寧で硬い。ブラントは低くゆっくり、数字を区切る。ザザは字義どおり。コルは一字も盛らない。
- 可笑しさ：「卵一つまで」、留め金のない隊長、「客でいい」、非番の女が刃も棍棒も持たずに騎士見習いを止める、オスカーの眼鏡、コルの字義どおりの伝言。
- 寒さ：雑費の行。誰も守らない亜人の銅貨。説教しない。
- 組織の手触り：数字は台詞の中で一つずつ出す。表を本文に入れない。
- 数字は漢数字。時刻は鐘。

## 11. 作者だけが知ること（本文に書かない）
- 二九〇年の子：作者用の仮決めとしてヴェイ（当時八つくらい）。洗濯女はヴェイの母。谷の者に抱えられて残った。ヴェイは匂いでマグダを覚えている（鉄と、血と、灯の油）。マグダはヴェイを見分けない。本文には何も書かない。採るかどうかは第10回の設計時に決める。
- エーリカが写した一行は『石の件ののち　参事ブラント　金貨百枚』。ブラントはそれが夫人の耳に入るのを何より恐れて、監査を引いた。エーリカは夫人に裏帳面のことを言っていない。
- ブラントは三一二年の霜月、紅玉の売り先として盗みに噛んでいた（城壁の中の故買屋はみな隊長か参事会とつながっている）。盗みが失敗してバルタザールが牢に入ると、帳面のことで脅された（「私が裁きで口を開けば」）。だから組合の建物を探させたかった。
- バルタザールが帳面を厩に隠した理由：誰も亜人の寝床を見ない。ザザは嘘をつけないが、誰もトカゲに何かを訊かない。
- マグダは、誰が監査を止めたかをエーリカだと見当をつけている。酒場番の手が入っているかもしれないとも思う。訊かない。
- マスターが裏帳面を自分の手札にしなかった理由は、作者も一つに決めない（家探しの気配そのものを店から遠ざけたかった、雇われの酒場番が参事の喉に指をかけてよいことはない、組合の物は組合に、のいずれでも読めるように）。

### 第9章「藁の下」
- 日と鐘：十五日の夜半すぎ（十六日の未明）。密度4。冒頭に密度1の段落（中庭の霜と井戸の釣瓶）。
- 場面：①中庭。霜。厩の階段を上る。マスターの靴は太くない。梁の上のコルは眠っている。ドゥンは窓の下で丸くなっている。ザザは奥の藁で目を開けている（熱で人が来るのが分かる）。②マスターは一つだけ訊く（第7節 Z1 の台詞を一字一句）。それ以上は訊かない。③ザザが藁からどく。床板の隙間に、油紙の包み。④灯を一つだけ。イゾルデの細い字。三参事への顔代（第2-6節）。マスターは行を指でたどり、数える。総額 金貨二百七十枚。余白の『席は春』。最後の行『石の件　懸賞金ののち　参事ブラント　金貨百枚』（済の印なし）。地の文：前の組合長が夫人の石を盗ませた件の、懸賞金の分け前、と一行で受ける。⑤マスターの勘定（地の文。短く）：この紙一枚で何ができるか。雇われの酒場番が持っていてよいものか。ザザ「持っていくのか」「借ります」「返すのか」「返すかどうかは、私が決めることではありません」。
- 伏線：Z1 回収／G1 回収（中身）
- 可笑しい瞬間：ザザ「どけと言われれば、どく」。マスター「どいてください」。ザザは三拍遅れてどく（寒い夜は体が遅い）。
- 章末の引き：マスターは包みを懐に入れて階段を下りる。天井の足音は、まだ鳴っている。
- 禁止：ザザに、寝床の下に物があるか以外を訊くこと（誰が置いたか、何を見たか、瓶、靴、三年前の秋）。マスターが帳面を自分で使う決心をすること。

### 第10章「二十三年前の朝」
- 日と鐘：十六日、夕方六つ〜七つ半（客のいない刻）。密度4。冒頭に密度1〜2の段落（夕べの祈りの鐘、軒の水）。
- 場面：①マグダ（私服）が来る。トマスも来る（マグダが呼んだ）。マグダ「明日には帳面がその頁に届く。その前に、お前に聞かせておく。帳場の小僧が、人づてに聞くのは癪だ」。②二十三年前の朝（第2-5節）。マグダの語りは短く、乾いて。台詞は一字一句（「届いたのは、私だけだった。背が高かったからだ」「子どもの顔は、覚えていない。手が、小さかった」）。暴力は一行、血は一行。③修道女が門の内で傷を閉じた。何も訊かなかった。オスカーが書いた。ハーゲンが連署した。ハーゲンは隊長になり、私を跡目に推した。死んだ。④トマス「転んだって、言ったっす」。マグダ「転んだのは、ハーゲンのほうだ。槍を取られて、尻餅をついた」。片側だけで笑う。⑤マグダが外套の紐を一度ほどき、結び直す。「春の議までに、私は隊長じゃなくなるかもしれん。それならそれで、予算が一人分浮く」。
- 伏線：T1 回収／M1 補強／K1 回収（一つ目と七つ目）
- 可笑しい瞬間：「それならそれで、予算が一人分浮く」。トマスが本気で計算しかけて、マスターに止められる。
- 章末の引き：マグダが帰る。マスターの懐で、油紙が乾いた音を立てる。マスターはそれをまだ誰にも見せていない。
- 禁止：子の名や個体を特定すること。マスターが裏帳面のことをマグダに言うこと。

### 第11章「一行」
- 日と鐘：十六日の夜十の鐘すぎ〜十七日の夕方五つ。密度3。
- 場面：①夜、二階。マスターが組合長の部屋の扉を叩く（足音が止まる）。「組合の建物で見つかった、組合の物です」とだけ言って包みを渡す。どこで、を訊かれたら「厩の二階で。ザザの寝床の下に」（事実）。誰が置いたかは言わない（マスターはザザから聞いていない）。エーリカは読む。灯の下で、狩人の目が行をたどる。②エーリカは一行だけを別の紙に写す。マスターからは何の行か見えない（地の文：一行、とだけ）。釘の封蝋で封をする。③十七日の朝六つ半。エーリカが中庭で梁のコルを呼ぶ。「ブラント参事に。返事は要らない」。コル「ブラント参事に。返事は要らない」と復唱して、梁から中庭の塀へ、塀から屋根へ上がっていく（飛ぶかどうかは書かない。屋根伝いに行く）。④エーリカは包みを持って厩へ上がり、ザザに頼む。「もう少し、その上で寝てくれる？」。ザザ「寝る」。マスターは中庭から、それを見ている。⑤夕方五つ、トマスが来て昼のことを話す（第2-7節の5。トマスの台詞を一字一句）。監査は取り下げ、隊長の謹慎は解けた、削り案は出し直し、遺族扶持は戻った、雑費は戻らない。
- 伏線：G1 回収（使い道）／O1 回収／S5（長い糸）
- 可笑しい瞬間：トマスが自分の答えを三回繰り返して、だんだん得意げになる。「書いてあるっす、って言ったっす」。
- 意図の薄い段落：封蝋を温める灯の煤。
- 章末の引き：コルが梁の上から言う。「隊の伝令の銅貨は、春から出ない。今日、そう言われた」（訊かれたのは「今日は隊の走りはあったか」）。
- 禁止：エーリカが写した行を書くこと。エーリカが手札の使い道を口にすること。

### 第12章「隊長の非番」
- 日と鐘：二十五日（隊の給金の日）、夜九つ。密度2。冒頭で、あれから八日たったことを示す。
- 場面：①給金の日の夜。客が多い。トマスが銅貨二枚を握って卵を買いに来る（底には触れない。卵の味だけ）。②マグダが灰色の外套で入ってくる。鉄を打った靴。胸当てはない。留め金は二つとも留まっている。カウンターに座り、上の一つを外す。③「樽は、まだか」「春の議のあとです」。「あれは三人への贈り物だ。私の分は、只酒じゃない」。マグダは誰が監査を止めたかを訊かない。天井を一度見上げる（組合長の部屋。今夜は鳴らない）。④コルの銅貨の話。マグダ「全部は守れない。予算で飯を食ってる」。自分の財布から銅貨二枚を梁の上へ投げる。「伝令の手間賃だ。一回分」。コル「受け取る。一回分、走る」。卵一つ分の銅貨で、春からの行は埋まらない。誰もそれを言わない。⑤マグダが麦酒の代金を置いて立つ。戸口で少しかがむ。
- 伏線：M1 回収／K1 回収（六つ目の冗談）
- 可笑しい瞬間：トマスが卵を食べながら、隊長の前で直立しようとして、椅子に足を取られる。マグダ「転ぶなよ」。
- 意図の薄い段落：給金の日の店の騒がしさと、銅貨の音。
- 結末の一文：マスターの乾いた一文。留め金か、銅貨か、天井のどれかに触れる。説明や教訓で締めない。
- 禁止：マグダの見立て。瓶の底。
