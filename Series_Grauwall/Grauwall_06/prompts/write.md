# このシリーズの鉄則
- 語りは三人称。場面ごとに視点人物を一人（フィン・ダリオ・リナ・ケス・テオのいずれか）。エルノ・使者・マスター・エーリカの内心を地の文で語らない。視点人物が見聞きしていないことは書かない。
- 嘘をつくのは台詞だけで、嘘の作法の条件を満たす者だけ。亜人は嘘をつけない。聖職者は嘘をつかない。城壁の外では組合の冒険者も嘘をつける。使者とエルノは、どこでも嘘をつける。
- 越えてはならない線（共通執筆ルール 2-11）を越えない。世界の理を壊す力、他の作品からの借用、ゲームの言葉を書かない。
- 紅玉の在りかを推し量らせない。温かい石の噂は第7章と第19章だけ。白塔の中、白塔の裁き、エルノの最期を描かない。
- 名前のある人物は、CANON 第4節の「欲しいもの／恐れているもの／理由」に沿って動かす。都合のいい駒にしない。
- CANON 第11節「作者だけが知ること」は、地の文にも台詞にも書かない。
- 一章は Web の一話として単独で読まれる。冒頭の数行で「いつ、どこで、誰が」を示し、段落は短めに、章末には小さな引きを置く。
- 可笑しさを一度は入れる。すべての文を効かせようとしない。
- CANON に無いものを新しく足すのは、作者の裁量としてかまわない。ただし CANON と正典に矛盾させないこと（足したものは章の記録に残る）。
