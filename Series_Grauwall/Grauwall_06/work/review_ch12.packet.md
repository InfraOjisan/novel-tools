# CANON

## 0. タイトルと要旨
- タイトル：白塔の使者
- 要旨：春の裁きで、去年の霜月に神官を騙った賢者エルノ・ファルクが白塔へ引き渡されることになる。護送を請けた一行は、南街道、川港ネーベル、川舟、山道を経て白塔の門まで囚人を届ける。途中で二度の襲撃があり、襲わせたのは使者の側だった。エルノは白塔の命令の真相を一人の嘘をつけない鴉人に預け、門の内へ自分の足で入る。

## 1. 舞台（抜粋）
### 1-1. 街・暦・鐘・城門・通貨と物価
- 灰壁暦三一三年、弥生。本作の期間は弥生十二日の裁きから、弥生の晦日の夕方六つまで。
- 鐘は一刻ごとに刻の数だけ鳴る。半刻は一打。朝六つで南門が開き、夕方六つで閉まる。夜のあいだは誰も出入りできない。
- **城壁の外では、大聖堂の鐘は聞こえない**（2026-10-11 追記）。街道・宿場・舟・ネーベル・ハウゼン・山道には、刻を打つ鐘はない。時刻は日の高さ・空の色・宿の刻み蝋燭（蝋燭に刻の線を引いたもの）で示す。宿の夕飯の合図は鈴。「夕方六つ」「夜半」などの刻の名は、鐘の音ではなく刻み蝋燭や見当として使う。
- 通貨：金貨一枚＝銀貨二十枚＝銅貨四百枚。
- 物価（正典の値）：麦酒一杯 銅貨五枚。煮込み一皿 銅貨十枚。下町の宿一泊 銀貨一枚。荷運びの駄賃（半日）銀貨三枚。

### 1-2. 嘘の作法・術・亜人の感覚（本文で使う形）
- 亜人（ケス）は嘘をつけない。黙る、はぐらかす、問いで返すことはできる。

- 聖職者（テオ）は嘘をつかない。「僕は嘘をつきません」と先に言うことがある。
- 組合の剣士（ダリオ）、魔法使い（リナ）は、組合の建物の中では仲間に嘘をつかない（鉄の誓約）。城壁の外では、普通に嘘をつける。
- 使者（メルヒオル・イルザ）とエルノは組合の外の者なので、どこでも嘘をつける。
- 賢者の囚人の縛り方：両の掌を胸の前で合わせ、手首から指の根もとまで革紐で巻く。祈りの形に見える。術は手から出るので、縛られているあいだは術を使えない。
- 賢者の術は攻めと灯の両方。ただし一人を倒せる程度を超えない。
- 胸の刺繍の違い（正典）：灯火教会は炎の芯が丸く、皿の下は短い脚が一本。白塔は炎の芯が尖った細い塔の形で、その下に小さな環があり、皿の下は下へ広がる三段の段。

- 視点人物の感じ方：ケス（鴉人）は遠目と高さ。テオは灯と正直さ。ダリオは髭と酒。リナは金と火。フィンは手帳と規則。

### 1-3. 南門と南街道、ネーベル、川、山道、白塔

- 川：ネーベルから東へ流れ込む支流を、舟でさかのぼる。雪解けで水が出ている。川霧が多い。

- 山道：ハウゼンから東の山あいへ。八里、登り六刻。灰岩の切通しがあり、獣道と石の段が続く。
- 白塔：東の山あいの台地に立つ。門と、門の前の庭まで描く。中は描かない。

## 2. 旅の仕組み（物語の論理）

**護送の依頼**：依頼主は市参事会。組合の依頼票として出す。報酬は金貨十二枚。前払い六枚。受け取りの印を白塔で得て戻れば残り六枚。印がなければ報酬は半分。隊が出せるのはフィン一人。残りは組合に頼む。

**白塔の使者の企み**：白塔は、上席の賢者の一人（上の方）から、エルノを「回収」するよう命じられた。エルノの去年の企み（紅玉「夜啼きの涙」を術で奪う）が白塔の名で露見するのを恐れたためである。白塔の表向きは弟子の引き取り。真は、エルノを白塔の内で処分すること。

ただし、公に処分すれば白塔の名に傷がつく。そこで使者が考えたのは、「勝手に出奔した者」にすることだった。道中でエルノを逃がし、逃げた者として白塔の名で始末する。その際、白塔は「勝手に出た者のしたこと」と言える。そのための手配を、メルヒオルは襲撃者にさせた。第一の襲撃は、エルノを逃がすことが目的（殺さず、生け捕り）。第二の襲撃は、逃がせなかった場合に備えて、山道で殺すことも含む（生け捕りを命じる。殺すのは最後の手段）。

**二度の襲撃**：
- 第一の襲撃（第9章・ネーベル、弥生十八日朝）：ネーベルの荷揚げ人ブルーノ（頭）と、その手下（クラウス含む四人）。周旋屋ゼーバルトを通じて金を受け取った。目的は囚人を生け捕りにして、路地へ逃がすこと。クラウスが一人、捕まる。ブルーノは逃げる。クラウスは雇い主の名を出さない（「金は酒場で渡された、顔は見てねえ」）。フィンは襲撃者の棍棒で肩に打ち身を負う。
- 第二の襲撃（第15章・山道、弥生二十一日）：川上の村ハウゼンの猟師グスタフと、若い猟師二人。舟の主ヤーコプから山道の案内を受けた。目的は、囚人を岩場で逃がすか、逃げなければ殺すこと。ダリオが囚人の革紐を解き、エルノが術で一行を守る（迫る者を一人ずつ止め、リナに小さな結界を張る。第5節の術の強さのとおり）。グスタフは逃げる。

**誰が指示したか（証はない）**：ゼーバルトには白塔の使者（メルヒオル）から金と「白塔の口利き」が渡された。イルザは金の出入りを算盤と帳面に書いた。ヤーコプは出発の日を、使者からまだ誰も聞いていない時点で知っていた（第13章の手がかり）。

**ネーベルでの白塔の動き（M1）**：ケスが、使者の一人（メルヒオル）がゼーバルトと舟宿の裏で会っているのを遠目で見る（第8章）。何を話したかは聞こえない。

**エルノの真実**：
- 白塔の命令：去年の秋、白塔は弟子の娘（ハンネ、十一。白塔の子ども部屋にいる）を人質として預かったまま、エルノに「夜啼きの涙」を得よと命じた。
- 命令の紙：エルノは命令を紙で求めた。メルヒオルの手で書かれ、上席の印が捺された一枚『夜啼きの涙を得よ』。下町の偽の礼拝所の灯台（油壺つき）の油壺の底に隠していた。
- 計画：前の組合長バルタザールの盗みに乗る。石が隊の前で出た瞬間に、術で奪って逃げる。石は出ず、霜月の夜に隊が来た。酒場で揉み合いになり、身に染みた攻めの術が先に出て、正体が割れた。
- 白塔の動き：白塔は、この件が上に知れることを恐れた。使者が来たのは「回収」のため。白塔が石を欲しがる理由は、エルノも知らない。
- 灯台は、礼拝所の物として隊に押さえられ、いまは詰所の証の棚にある。命令書はまだ油壺の底にある。隊の手の中で、白塔には手が届かない。

**門の前の取引（第16章）**：エルノはメルヒオルに、命令書が城壁の内にあり白塔の手が届かないことだけを告げる（在りかは言わない）。その代わりに、娘ハンネと一行に手を出さないことを約させる。エルノは逃げず、自分の足で門をくぐる。メルヒオルは呑む。

**術と正典**：襲撃は、人が人を襲うだけで、術は使わない（襲撃者は魔法使いを持たない）。エルノの術は一人を倒せる程度。リナの火は一つの攻め。すべて設定資料 2-2 の範囲内。

## 4. 人物

各人に：名前・種族・職・年齢・外見・癖・持ち物・嘘をつけるか・呼び方、欲しいもの／恐れているもの／この回の行動の理由。

### 一行
- **フィン**（人間・男・二十代後半・治安維持隊の隊員、町廻りの班の頭役）。外見：背が高く、灰色の外套の襟を立てる癖。持ち物：手帳と鉛筆（黒い炭の棒）、引き渡し状。嘘：組合の外の人間なので、城壁の外では嘘をつける。この回では嘘をつかない（つく場面は作らない）。呼び方：「フィンさん」（組合の者から）、「フィン」（ダリオ）。
  - 欲しいもの：受け取りの印を持ち帰り、報酬を取り、隊長に報告すること。
  - 恐れているもの：手帳の記録が違っていること。
  - 理由：務めとして引き受けた。隊の予算を一人分で守った自分の判断の結果を、きちんと持ち帰りたい。
- **ダリオ**（人間・男・三十代・剣士）。外見：大男。髭の端が縮れている。持ち物：背の大きな剣、酒の小瓶。嘘：組合の剣士なので、城壁の外では嘘をつける。呼び方：「フィン」「テオ」「賢者」。
  - 欲しいもの：酒と、髭が元どおりになること。
  - 恐れているもの：仲間を失うこと。
  - 理由：去年の霜月に髭を焦がされた貸しを、賢者に返させたい（冗談として）。報酬はそこそこ。
- **リナ**（人間・女・十六・魔法使い）。外見：麦藁色の髪。父のお下がりの杖。緊張すると杖を握りしめる。嘘：組合の魔法使いなので、城壁の外では嘘をつける。攻めの術（火・雷・氷）だけ。呼び方：「賢者さん」（エルノ）、「テオさん」。
  - 欲しいもの：金と、自分の術が役に立つこと。
  - 恐れているもの：足手まといになること。
  - 理由：安い報酬だが、賢者の術を近くで見られる。
- **ケス**（鴉人・性別は男、組合の外の雇われの斥候）。外見：黒い羽。細い首を傾ける癖。持ち物：組合の屋根の上で拾った黒い布の切れ端を一枚。嘘：嘘をつけない。黙る、はぐらかす、問いで返すことはできる。呼び方：「鴉」（ダリオ）、「ケス」（フィン）。
  - 欲しいもの：高い所と、見晴らしのよい屋根。
  - 恐れているもの：見たことを、見ていないと言わされること。
  - 理由：白塔が高い山の上にあると聞いた。一行の中で、いちばん遠くが見えるのが自分だと知っている。
- **テオ**（人間・男・二十二・灯火教会の修道士）。外見：小柄。手燭を持ち歩く。白い手袋はしていない。持ち物：手燭、小さな祈りの本。嘘：灯の前の誓願により嘘をつかない。癒しの術は使えるが上手ではない。攻めの術は使えない。呼び方：使者を「賢者様」、フィンを「フィンさん」、ダリオを「ダリオさん」。
  - 欲しいもの：務めを正直に果たすこと。大聖堂に報告すること。
  - 恐れているもの：嘘をつかないために、人を困らせること。
  - 理由：アガタが推挙した。アガタの期待に応えたい。白塔の門の内を見て帰ることを務めとしている。

### 囚人と使者
- **エルノ・ファルク**（人間・男・四十四・白塔の賢者・囚人）。外見：細い指。白い法衣。袖口に焦げが二つ。指が落ち着かず、袖の中で組み替える癖。持ち物：なし。嘘：組合の外の者なので、どこでも嘘をつける。呼び方：「賢者様」（テオ）、「ファルクさん」（フィン）、「エルノさん」（ダリオは「賢者」と呼ぶ）。
  - 欲しいもの：娘ハンネが塔の子ども部屋で安全に育つこと。塔の正式な弟子の席が、娘に与えられること。
  - 恐れているもの：娘が人質のまま、自分が口を塞がれ、娘が代わりに払うこと。
  - 理由：白塔の掟により娘は塔に預けられている。断れば娘が払う。果たせば席と娘の行く末が約される。果たしても口を塞がれるかもしれないと分かって請けた。最後は逃げれば娘が払うと分かっているので、門をくぐる。
- **ハンネ**（人間・女・十一・エルノの娘。作者のみ知る。本文には一度も登場しない）。
  - 欲しいもの：字を覚えて、いつか塔の正式な弟子の席に座ること。
  - 恐れているもの：父が戻らず、約された席も消えること。
  - この回の行動の理由：本文には登場せず、行動もしない。掟により塔の子ども部屋に預けられている。父が果たせば席が約されているので、そのまま塔にいる。エルノの台詞の中にだけいる。
- **メルヒオル**（人間・男・六十がらみ・白塔の上席の賢者・使者）。外見：痩せて、物腰が柔らかい。声が小さい。手袋をしている。持ち物：白塔の封蝋のついた書状。嘘：組合の外の者なので、どこでも嘘をつける。呼び方：「賢者」（テオ）。
  - 欲しいもの：上席の座を守ること。回収を、白塔の内で穏便に済ませること。
  - 恐れているもの：命令書が世に出て、上席の印が問われること。上の方（名は出さない）の怒り。
  - 理由：上から回収を命じられた。襲撃は、エルノを逃がして「出奔」にするための手。自分の座と白塔の名を守る。
- **イルザ**（人間・女・三十代の終わり・白塔の賢者・書記役）。外見：きびきびして、背筋がまっすぐ。手帳と小さな算盤を持つ。嘘：組合の外の者なので、どこでも嘘をつける。呼び方：「イルザさん」（フィン）。
  - 欲しいもの：白塔の帳面が正しく付くこと。自分の仕事が正確であること。
  - 恐れているもの：自分の付けた金の帳面が、誰かの手で読まれること。
  - 理由：メルヒオルの書記として、金の行き先を付けた。上司に従う理由は、自分の仕事を最後まで正しく終えたいから。エルノとは同じ年に白塔に入った。
  - 作者の決め（第11節に詳しく）：ハンネの名を知っている。

### 呼び方の規則
- 白塔の者は、エルノを「ファルク」と呼ぶ（使者の立場）。
- テオは使者を「賢者様」と呼ぶ。
- 組合の者は「殿」を使わず、組合の外の人には「さん」。
- フィンは隊の同僚に「殿」を使わない（隊の中では呼び捨て、隊長には「隊長」）。
- ケスは、名前で呼ばれたら一言だけ返す（「ケス」）。
- 亜人の名は、人間の語彙（「鴉」「灰色」）で呼ばれる。ケスは「鴉」と呼ばれる。

## 5. 小道具と数値
- 報酬：金貨十二枚。前払い金貨六枚。受け取りの印で残り六枚。印がなければ半分（残りの金貨六枚が出ない）。
- 舟賃：ネーベル→ハウゼン、舟一艘 金貨二枚（八人、荷を含む）。ハウゼン→ネーベル（帰り）、金貨一枚半。

## 11. 作者だけが知ること（作者が把握する真実。【第14章で台詞として出す】の項目だけ、本文に出る）

- 命令書の文面：『夜啼きの涙を得よ』。メルヒオルの手、上席の印。下町の偽の礼拝所の灯台（油壺つき）の油壺の底に、折って蝋で留めて隠した。去年の霜月の捕縛のあと、灯台は隊に押さえられ、いまは詰所の証の棚にある。命令書はまだ油壺の底にある。

15. ending（最終章のみ）：新しい事件を起こさず、長いエピローグや教訓で締めていないか。

# 審査の進め方
- 原稿を一度通読し、各項目を一度ずつ確かめる。同じ箇所を何度も検討し直さない。
- 判断に迷う点は、結論を出そうと粘らず、severity "low" として detail に「判断保留：…」と書いて先へ進む。
- 嘘の判定（項目3）は、話し手の種別（設定資料 2-1 の表）と場所（組合の建物の中か外か）だけで決める。

次のJSONだけを出力してください。前置きや説明、コードブロックは不要です。

{"pass": true または false, "slots_found": {"スロットID": "planted / reinforced / recovered / none"}, "violations": [{"severity": "high" または "low", "type": "canon / narration / lies / line / series / secret / premature / slots / role / web / continuity / insert / meta / typo / ending", "detail": "どこがどう問題か（原稿の該当箇所を短く引用）", "fix": "どう直すか（具体的に）"}]}

- slots_found には「この章の伏線」に挙がっているスロットを必ずすべて含める。
