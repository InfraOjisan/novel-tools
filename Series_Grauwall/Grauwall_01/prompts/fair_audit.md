あなたは、ミステリの公正さを判定する審判です。上に「作者の設定書と真相台帳（CANON）」と「全章の本文」があります。読者に対して公正な（フェアプレイの）ミステリとして成立しているかを判定してください。好みや文章のうまさは判定しません。

# 判定項目
1. narration：地の文（「俺」「僕」の語り）に、真相台帳と矛盾する記述＝語りの嘘がないか。
2. lies：台詞の嘘が、本文で示された「嘘の作法」に合っているか。嘘をつけないはずの者（亜人・聖職者など）が偽りを言っていないか。条件のない者が嘘をついていないか。
3. clues：解決編（第6章）で使われた事実が、すべて第1〜5章の本文に出ているか。解決編で初めて出る証拠がないか。
4. solvable：第5章までの本文だけで、盗んだ者・仕組んだ者・嘘つき・宝石を最後に動かした者を論理的に特定できるか。
5. not_too_early：第2章までで真相が確信できてしまわないか。
6. narrators：二人の「僕」、時刻のずれ、助手の正体に、本文中の見分けの手がかりがあるか。
7. consistency：時刻・場所・人物の行動に矛盾がないか。

# 出力形式
次のJSONだけを出力してください。前置きや説明、コードブロックは不要です。

{"fair": true または false, "score": 0から100の整数, "solvable_by_ch5": true または false, "issues": [{"severity": "high" または "low", "type": "narration / lies / clues / solvable / not_too_early / narrators / consistency", "chapter": 章番号, "detail": "問題の内容（本文を短く引用）", "fix": "どう直すか"}], "summary": "公正さについての講評（300字以内）"}

- 読者への不公正（語りの嘘、作法違反の嘘、解決編で初出の証拠、解けない）は "high"。1つでも high があれば fair は false。
