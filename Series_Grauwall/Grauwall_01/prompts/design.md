# やること
- 上の「BRIEF」をすべて読み、その要件を満たす叙述ミステリを**あなた自身の発想で**設計してください。
- 「CANONテンプレート」の「（記入）」をすべて具体的な内容に置き換え、CANON全体を出力してください。
- 伏線スロットの中身と各章での見せ方は、配置表（BRIEF 4-2）の章番号どおりにしてください。
- 章カードは第1章〜第7章の7枚すべて。`<!-- CARD:nn -->` と `<!-- /CARD:nn -->` の目印はそのまま残してください。

# 設計の順番
1. 真相（盗んだ者・仕組んだ者・動機・方法・計画が狂った理由）
2. 真相台帳：鐘の刻ごとの時刻表（全員の居場所）
3. 嘘の一覧：嘘の作法の条件を満たす嘘だけを置き、嘘を取り除けば真相と一致するようにする
4. 二人の「僕」の節の表と、時刻のずれ
5. 各章の盤面（二転三転）と二重読み表
6. 結末、不変条件、文体、解答キー、章カード

# 自己点検（出力前に確認し、問題があれば直してから出力する）
- 亜人と聖職者の台詞に、嘘が一つもないか。条件のない者に嘘をつかせていないか。
- 地の文で使う予定の記述が、時刻表と矛盾しないか。
- 第5章の終わりまでに、解決に必要な手がかりがすべて出るか。
- 解決が、第1章で示す嘘の作法だけで成り立つか。
- 最後の会話（BRIEF 第1節）が第7章に置かれているか。
- 全体が32,000字以内か。

# 出力形式
- 1行目は `# CANON` で始める。
- CANON以外（前置き、説明、自己点検の結果）は出力しない。コードブロックで囲まない。
