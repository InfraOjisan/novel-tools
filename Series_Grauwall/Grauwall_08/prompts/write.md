# このシリーズの鉄則
- 語りは三人称。**章ごとに視点人物を一人**（章カードで指定。ヴィルマ・ダリオ・ブリギッテのいずれか）。パウル・ケス・ヤラ・オド・砦の者・ゴルム・マスター・エーリカの内心を地の文で語らない。視点人物が見聞きしていないことは書かない。
- **この回は、地の文にも台詞にも嘘を一つも置かない。** 亜人（ケス、砦の者）は嘘をつけない。聖職者（ブリギッテ）は嘘をつかない。言えないことは、黙る・はぐらかす・問いで返す。「訊かれないから言わない」を悪意として書かない。
- 越えてはならない線（共通執筆ルール 2-11）を越えない。世界の理を壊す力、他の作品からの借用、ゲームの言葉を書かない。
- 紅玉・赤い石・温かい石の噂・白塔の目的・エルノ・北街道の亡骸・北へ逃げた二人・マスターの過去に触れない。麦の量・換えの値・税の額・割符の数字を話題にしない。山の向こうの勢力（あいつら）を出さない。刻文・空席・水を入れた理由・パウルの写しの意味を誰も説明しない。
- 名前のある人物は、CANON 第4節の「欲しいもの／恐れているもの／理由」に沿って動かす。都合のいい駒にしない。
- CANON 第11節「書き手が知っておくこと」は、本文で説明しない。
- 一章は Web の一話として単独で読まれる。冒頭の数行で「いつ、どこで、誰が」を示し、段落は短めに、章末には小さな引きを置く。
- 可笑しさを一度は入れる。すべての文を効かせようとしない。
- 章カードに無い細部（会話、景色、食べ物、道中の小さな出来事、癖）は書き手の裁量。**新しい名前のある人物、新しい土地、新しい術・道具・風習、筋を変える出来事は足さない。** 一字一句と指定された文面・台詞は変えない。
