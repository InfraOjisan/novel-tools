# 依頼：物語の「分岐の地図」を作る

あなたは小説の下読み役です。同じフォルダの `TEXT.md`（ある長編ミステリの全文）を読み、**この物語の結末や解釈を、本文を書き換えずに（または最小の書き換えで）別の方向へ揺らせる箇所**を探してください。

目的は、一本の物語から「ループもの」「平行世界もの」「分岐のあるゲームシナリオ」「続編の謎」の種を見つけることです。誤りや矛盾の指摘ではありません。

## 守ること

- 読んでよいのは `TEXT.md` だけです。このフォルダの外のファイルを開かないでください。ウェブも検索しないでください。作品について本文以外の知識があっても使わないでください。
- 本文の引用は、`TEXT.md` の文をそのまま写してください（要約しない。80字まで）。
- 答えは `results/` に JSON で書いてください（ファイル名は依頼者が指定します）。JSON 以外は書かないでください。

## 揺らぎの信号（こういう所を探す）

| 信号 | 説明 |
|---|---|
| 観測の空白 | 起きたはずなのに、誰も見ていない（本文が描いていない）時間・場所・出来事 |
| 単一証言 | 一人の知覚や一人の言葉だけが支えている事実 |
| 識別のぼかし | 名前ではなく、種族・役・見た目・代名詞でしか呼ばれない人物。誰も確かめていない身元 |
| 字義と含意の差 | 字義どおりには正しいが、聞き手（や読者）がそれより広く受け取っている言葉 |
| 時刻の幅 | 時刻がはっきりしない出来事。並べ順と実際の順がずれうる所 |
| 選ばれなかった問い | 人物が別の訊き方・別の確かめ方をできたのに、しなかった場面 |
| 使われていない例外 | 世界の決まりの抜け道で、まだ使われていない、または使われたかどうか分からないもの |
| 追われていない物 | ある場面のあと、所在や中身が書かれなくなる物 |
| 語られない動機 | なぜその人物がそうしたのか、本文が本人の口から確かめていない行い |

## 一つの分岐点について書くこと

1. `quote`：その箇所の本文（そのまま）。
2. `signal`：上の信号のどれか（複数可）。
3. `question`：何が決まっていないのか（一文）。
4. `values`：取りうる値を二つ以上。本文の表の読み（多くの読者がそう読む値）を必ず一つ入れ、`reading: "surface"` を付ける。ほかは `reading: "alt"`。
   - それぞれに `consistent`（本文と矛盾しないか。矛盾するなら、どの文と）と、`converges_to`（その値を取ると、結末や人物の関係がどちらへ向かうか）。
5. `cost`：表の読み以外の値にしたとき、書き換えが要る本文の文の数（0 なら「本文を一字も変えずに開ける」）。
6. `impact`：結末や主要人物の見え方への効き（1〜5）。
7. `forms`：向いている形（`loop`：主人公が知識を持ち越すと開く／`worldline`：外の出来事が一つ違えば開く／`game`：選択一つで開く／`sequel`：続編の謎になる）。
8. `sprouts`：その値を見分ける手がかりになる本文の箇所（そのまま引用）。なければ空。
9. `close_by`：この分岐を閉じる（一つの値に確定させる）なら、どんな一文を足せばよいか。

## 並べ方

`cost` が低く `impact` が高いものを上に。多くて15件。
