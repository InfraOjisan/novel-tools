# mx01 — 知覚の投影でミステリを書かせる実験（最小構成）

グラウヴァル番外『七つの鐘の鴉』（仮題）。日常の謎・全3章・約1万字。正典には入れない。

## 何を確かめるか

生成AIに BRIEF/CANON から書かせると、ミステリが成立しにくい。理由は三つあった。

1. 書き手が真相を知っている。知っていることは「親切に」埋めてしまう。
2. 審査が「明瞭さ」を見ている。錯誤を起こす文は欠陥として落ちる。
3. CANON が自然言語なので、マスクしても推論で補われる。

この実験の仮説：**トリックを書き手の意図ではなく、入力の欠落で作る。**

- 真相は構造化した台帳（`truth/WORLD.yaml`）に置く。人物・場所・時刻・出来事・**誰が何をどう知覚したか**・台詞の真偽。
- 台帳は機械で検査する（同時に二か所にいない、移動時間、見える場所にいたか、嘘をつけない者が偽りを言っていないか、取り違えが宣言した死角で説明されるか、手がかりが解決章より前に視点人物へ届くか）。
- 書き手には、**視点人物が知覚したことだけ**を投影したパケットを渡す。書き手は真相を知らないので、視点人物が取り違えていれば、書き手も取り違えたまま「正しく」書く。地の文は嘘をつかないまま、錯誤が自然に起きる。
- 審査を二つに分け、合格の向きを反転させる。真偽監査（真相を見る）は「嘘は不可、錯誤は可」。読者審査（真相を見ない）は「**設計どおりに誤読したら合格**、早すぎる看破は不合格」。

## 誰が何を見るか（情報の壁）

| 役 | 見てよいもの | 見てはいけないもの |
|---|---|---|
| 作者（プロデューサーと Claude） | すべて | ― |
| 書き手（第1・2章） | `dist/writer_chNN/` だけ（パケット・依頼文・前の章） | `truth/`、`out/author/`、このフォルダ全体 |
| 書き手（第3章・解決） | 第3章のパケット（真相を含む） | 第1・2章とは別の書き手が望ましい |
| 読者役（読者審査） | `dist/reader_chNN/` だけ（本文） | ほかのすべて |
| 真偽監査 | `truth/WORLD.yaml` と本文 | ― |

`GOVERNANCE`（ep03）の層1「秘密を作業フォルダに置かない」と同じ考え方で、書き手と読者役には `dist/` の箱だけを渡す。箱を作るときに `leak_tokens` の漏れ検査をし、引っかかれば箱を作らない。

## 流れ

```
python3 tools/mx.py all                 # 検査 → タイムライン図 → パケット → 漏れ検査
python3 tools/mx.py pack writer 1       # 書き手に渡す箱 dist/writer_ch01/
   → 書き手が chapters/ch01.md を書く
python3 tools/mx.py verify 1 chapters/ch01.md   # 固定の台詞・鐘・真相語
   → 真偽監査（prompts/truth_audit.md）
python3 tools/mx.py pack reader 1       # 読者役の箱。答えを out/author/READER_KEY.md と照合
   → 第2章も同じ。第2章のあとの読者審査では「推理しうる」かを見る
python3 tools/mx.py pack writer 3       # 解決章（真相入り）
   → 解決後、読者役に第1・2章を読み返させ、手がかりが「書いてあった」かを判定
```

## ファイル

| パス | 中身 | 見る人 |
|---|---|---|
| `truth/WORLD.yaml` | 真相台帳（出来事57・知覚22・言明24・死角1・解答キー） | 作者・監査 |
| `tools/mx.py` | 検査・投影・漏れ検査・箱づくり | 作者 |

| `prompts/` | 書き手・真偽監査の依頼文 | 各役 |

## この話の死角（一つだけ）

認識の死角。人間には鴉人の個体が見分けられない。設計の中身は `truth/WORLD.yaml` の `blind_spots` と `solution`、図は `out/author/TIMELINE.html` の第4日。

## 次に試すこと

- 同じ台帳の上で、死角を**時間**（鐘の数え違い・半刻の一打の取り違え）や**場所**（似た二つの部屋）に替えた版。
- 書き手を Aion／HermesAgent／別の Claude に替えて、同じパケットからどれだけ「辻褄合わせ」が起きるかを比べる（真偽監査の `smoothing` の数）。
- 視点人物を替える（フーゴ視点にすると、取り違えが地の文の内側に入り、叙述ミステリに近づく）。
