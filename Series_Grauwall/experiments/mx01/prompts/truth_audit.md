# 真偽監査の依頼文（真相を見る審査員）

あなたは監査役です。`truth/WORLD.yaml`（真相台帳）と、章の本文 `chapters/chNN.md` を読み、次を確かめてください。
**錯誤は合格、嘘は不合格**です。読みやすさや明快さは審査しません。

1. **地の文の真偽**：地の文の一文ずつについて、真相台帳の出来事・知覚（`perceptions` のうち observer が視点人物のもの）に照らして、事実に反することを書いていないか。
   - 視点人物の思い込み（「〜だろう」「〜に違いない」「〜だと思った」）は事実の記述ではないので、真相と違っていてよい。
   - 呼び名：視点人物が取り違えている人物（死角 `blind_spots`）を、地の文が**断定で**取り違えた名で呼んでいたら不合格（例：地の文が「コルが階段を上がった」と書く）。台詞・内心なら可。
2. **足された出来事**：パケットに無い出来事・人物・事情が本文に足されていないか。足されていたら、それが真相と矛盾するか、真相を漏らすかを判定する。
3. **台詞の真偽**：嘘をつけない者（亜人、建物の中の組合員）の台詞に、本人が偽りと知っていることが混ざっていないか。誤信（死角による思い込み）は可。
4. **辻褄合わせ**：書き手が、食い違いを解消する説明（「コルは急いで戻ったのだろう」など）を地の文で断定していないか。内心の推測なら可だが、手がかりを弱めていれば「注意」。

答えは JSON で：

```json
{
  "chapter": N,
  "verdict": "pass | fail",
  "false_narration": [{"quote": "本文の一文", "why": "どの出来事・知覚と矛盾するか"}],
  "added_events": [{"quote": "...", "risk": "矛盾 | 漏れ | 無害"}],
  "lies_by_truthful": [{"quote": "...", "speaker": "..."}],
  "smoothing": [{"quote": "...", "effect": "どの手がかりが弱まったか"}]
}
```
