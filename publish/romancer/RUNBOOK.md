# Romancer 公開手順書（Goose / Hermes / 人間 共通）　v2

対象：`Series_Grauwall/Grauwall_NN/output/`（や `Novel_N/output/`）の完成EPUBを、**Romancer（ボイジャー）で縦書きの電子書籍として公開**し、その公開URLを小説家になろうのあらすじに併載の一文として貼る。

- Romancer：https://romancer.voyager.co.jp/
- v2（2026-10-02）：第二話『新しい組合長』の登録で実際の画面を確かめて書き直した。v1 の「docx 必須」は誤り。**EPUB をそのまま原稿ファイルにできる。**

## 守ること（エージェント向け）
1. **パスワードは入力しない。** ログインは人間が行う。ログインはトップページの「ログイン」から（`/wp-admin/` に未ログインで直接行くと 404 になる。ログイン直後も一度 404 が出ることがあるので、そのときは同じURLを開き直す）。
2. 公開（BinB公開状態＝「公開」）は、人間がその作品について公開を頼んだときだけ行う。公開状態はあとからいつでも切り替えられる。
3. 作品の削除・アカウント設定の変更はしない。
4. **公開登録の画面に出る個人情報（氏名・住所・電話など）は読み上げない・書き写さない・入力しない。** 欄が埋まっていなければ止めて人間に頼む。
5. 想定外の画面・エラーが出たら中断して人間に報告する（リトライを繰り返さない）。
6. 公開URLは推測しない。画面に出たURLを、そのまま `publish/narou/works.json` の `romancer_url` に記録する。

## 前提（仕組み）
- 原稿ファイルは **EPUB / docx / PDF / 画像** を受け付ける。うちは `make_epub.py` で作った縦書きEPUB（表紙入り）をそのまま使う。無料プランの上限は 50MB。
- Romancer で作った EPUB を取り出すのは有料（手元の EPUB を使うので不要）。
- **シリーズ機能はない。** シリーズは「サブタイトル（後）」と作品紹介文の相互リンクで示す。
- 公開状態は 3 段階：非公開 → 限定公開 → 公開。**公開状態によって URL が変わる**ので、なろうに貼るのは「公開」にしたあとの URL。
- 閲覧は BinB（ブラウザビューア）。URL の形：`https://r.voyager.co.jp/epm/e1_<作品ID>_<日時>`

## 手順
1. **ログイン**（人間）：トップの「ログイン」からログインし、管理画面を開いた状態で渡す。
2. **新規追加**：`https://romancer.voyager.co.jp/wp-admin/post-new.php?post_type=epmbooks`（一覧は `edit.php?post_type=epmbooks`）。
3. **原稿ファイル**：「原稿ファイル」に `output/<題名>.epub` を指定（Chrome拡張の file_upload は `/mnt/user-data/uploads/...` に stage したパスだけ通る）。
4. **書誌情報**（赤字が必須）：
   | 項目 | 欄 | 値 |
   |---|---|---|
   | 作品名（画面上の大きな欄） | `#title` | 題名 |
   | タイトル（書誌情報） | `#otitle` | 題名 |
   | タイトル（カナ） | `titleruby` | カタカナ |
   | 著者 | `#author1` / `author1_r` | チームジョバンニ |
   | サブタイトル（後） | `subtitle_a` | グラウヴァル　第N話 |
   | ジャンル | `#jan1` / `#sjan1` | 書籍 / 小説・文学 |
   | 作品紹介 | `#description` | `publish_meta.md` のあらすじ＋前の話の題名と URL |
   | 作者コメント | `#acomment` | AI執筆・人間監修の表記 |
5. **変換情報**：既定のまま（綴じ方向 `ppd=rtl`、目次自動作成・表紙あり等はチェック済み）。
6. **変換**：左下の「変換」（`publish2`）→ 著作権の確認「この作品は、私の著作物です…」に **はい**（`register_confirm_yes`）。自分たちの作品であることを確かめてから押す。
   - 押すと「データを保存しています」→ 作品編集画面に「変換状態」の進捗（epubファイルチェック 1/11 …）が出る。数分かかることがある。画面は自動で更新されないので、ときどき再読込する。
   - **途中でセッションが切れた場合**：一覧に題名だけの下書きが残る（書誌情報は空、原稿ファイルなし）。新規に作り直さず、その下書きの「編集」から入力し直して「変換」すればよい。
7. **作品編集画面**：変換が終わると作品編集画面になる。「BinB公開状態」（`#publicasetting`）を **公開** にする。
   - 公開登録のモーダルが出る。登録済みの情報が入っていれば「公開する」（`#publica_register_ok`）。空なら止めて人間に頼む（守ること4）。
8. **URL を取る**：作品編集画面の BinB URL をそのまま控える。
9. **表示確認**：URL を開いて確かめる。
   - 縦書き・右綴じ
   - 表紙が出る
   - 目次に第一章〜最終章と奥付が並ぶ
   - 第一章の冒頭の一文と、最終章の最後の一文が出る
10. **記録**：`publish/narou/works.json` の `romancer_url` に書く。
11. **前の話との相互リンク**（任意・人間の了解を取ってから）：前の話の作品紹介に次の話の題名と URL を足す。編集で URL が変わらないかを確かめる。
12. **なろうへの併載追記**：`publish/narou/RUNBOOK.md` の「あらすじへの併載追記(Romancer)」を、記録した URL で行う。

## 終了条件（報告に含めること）
- BinB の公開 URL（公開状態が「公開」）
- 手順9の確認がすべて済んだこと
- `works.json` に `romancer_url` を記録したこと

## 公開時の確認画面（第二話で確認）
「公開」を選ぶと「作品を公開する前に」が出る。
1. 「はい、規約を守っています（利用規約 第15条 禁止事項）」のチェック ── **規約への同意にあたるので、作品ごとに人間のOKを取ってからチェックする。**
2. 出版者の連絡先（氏名・住所・電話・法人名）── 登録済みの内容が入っている。触らない・書き写さない。
→「公開する」。そのあと作品編集画面を開き直すと、BinB URL が `r.voyager.co.jp/epm/...` の公開URLに変わっている（非公開のときは `romancer.voyager.co.jp/ext/wp_read.php?...` の確認用URL）。

## 表示確認のコツ
BinB は本文を画像で描くので、ページのテキストは取れない。表紙・扉・第一章の冒頭は画面で確かめ、目次と最後の一文は、渡した EPUB の `nav.xhtml` と最終章で確かめる（Romancer は EPUB をそのまま表示する）。キーボードでのページ送りは反応しないことがある。
