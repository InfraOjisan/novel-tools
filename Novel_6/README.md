# Novel_6 — mx02 孤島の洋館（叙述ミステリ・デジタルツインの一作目）

企画メモは claude.ai のプロジェクト「小説を書こう」の `claude/mystery/mx02/企画メモ_v1.md`。

人物をエージェントとしてデジタルツインの上で動かし、その記録を**真実台帳**にする。
語り手の選択と散文化は後段。ここにあるのはその手前、「何が起きたか」と「誰が何を知覚したか」まで。

## 動かし方

```
python3 tools/sim.py batch 500 --top 5   # 500回まわして採点 → runs/SCOREBOARD.md、上位5回を runs/seedNNNN/
python3 tools/sim.py run 438             # 一回だけ（同じ seed なら同じ結果）
```

Python 3.10＋PyYAML。500回で30秒ほど。

## ファイル

| パス | 中身 |
|---|---|
| `twin/MANSION.yaml` | 洋館のデジタルツイン：部屋、通路、視線、音（壁・床）、夜の暗さ、錠、出口、窓の景色 |
| `cast/CAST.yaml` | 10人の性向（殺意・用心・社交・外出）と役（語り手・トリックスター・置き石）、予定（食事・就寝・遺言・迎えの船） |
| `tools/sim.py` | シミュレーション・物理の検査・採点・出力 |
| `runs/SCOREBOARD.md` | 採点の上位30回と分布 |
| `runs/seedNNNN/truth/LEDGER.yaml` | 真実台帳：死、出来事、言明（嘘には隠した出来事の印）、全員の滞在 |
| `runs/seedNNNN/truth/PERCEPTIONS.yaml` | 人物ごとの知覚ログ：見た／人影（暗がりで顔が分からない）／聞いた（方向だけ）／聞かされた／見つけた／自分のしたこと／最期 |
| `runs/seedNNNN/out/SUMMARY.md` | 作者用の要約：死の表、嘘、東西の取り違え、出来事 |
| `runs/seedNNNN/out/TIMELINE.html` | 人物×時刻の図（15分刻み。色＝棟、薄い＝眠っている、黒＝死、✕＝手を下した、赤い破線＝東西を取り違えている） |

`truth/` と `out/` は作者だけが見る。

## 舞台の仕掛け（ツイン側）

- 二階の東棟と西棟は鏡写し。客室の番号は両棟とも「一号室〜四号室」。
  人物が真実を言っても「三号室」はどちらの三号室か分からない（S2 同定の種）。
- 違いは窓の外（西：灯台の灯、東：桟橋）と、裏階段の下りた先（西：遊戯室、東：図書室）。
- 夜の暗い回廊から棟へ曲がるとき、東西を取り違えることがある（S5 取り違え）。鍵が合わない・部屋の中が違う・灯台が見える、で気づく。
- 錠：外からは鍵、内側はつまみ。内から出て閉めても掛からない。
  密室は「合鍵で外から掛けた」か「自分で内から掛けて、中で遅れて効く毒で死んだ」でしか起きない。
- 死体が消えうるのは崖から海へ落ちたときだけ。

## 人物の動き（v0 は規則ベース）

- 共通の賭け金：「四日目朝の迎えの船まで島に残った者で遺産を等分する」。初日の夕食で読み上げられる。
- 殺意が高い者は遺言の直後から、中くらいの者は死体が見つかるたびに「先にやらなければ」と決める。
- 犯行は、相手と二人きりで、誰からも見えないときだけ。毒は水差し（相手の部屋に忍び込む）か、食事の杯（皆の前で。ときどき見られる）。
- 死体が見つかると全員が集まり、医師がいれば死亡推定時刻を言い、各自が「どこにいたか」を言う。
  手を下した者は、二人以上に見られていない区間だけ自室にいたと偽る。トリックスターは気まぐれに偽り、他人の偽の目撃も言う。
- 聞き手は自分の知覚と食い違う申し立てに気づき、その相手を疑う（次の標的になる）。

## 検査

`batch` は毎回、物理の検査をする：瞬間移動・滞在の切れ目、殺人のとき二人が同じ場所にいるか、知覚した相手が本当にそこにいたか、真とした申し立てが滞在と合うか、偽の申し立てに理由があるか。v0 の500回で違反0件。
