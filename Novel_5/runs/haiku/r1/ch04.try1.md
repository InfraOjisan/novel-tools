# 第4章　選択

翌朝の計器室は、夜のうちに冷えた空気で満ちていた。暖房の吹き出し口が一定の音を立てているのに、床の金属だけがいつまでも冷たかった。私は掘削孔の水位を読み上げた。昨夜から変わらず、一時間に一ミリメートルずつ下がっている。

久米さんが全員を呼び集めた。ヴォスさんは培養室から出てきた。白衣の袖口が濡れて、手の甲が赤くなっていた。

「一度、整理しよう」と久米さんは言った。「我々に何ができて、何ができないかを」

ヴォスさんが画面に表を出した。水位、割れ目の長さ、温度の揺らぎ。その下に、培養器の数字と、割れ目の水の化学の値が並んでいた。

「この水は、炭酸水素イオンを含んでいます。弱いアルカリで、酸を少しずつ中和する。だから、酸を入れれば、まず炭酸水素と反応して、二酸化炭素の泡になって抜けてしまう。その分の酸は働かない。割れ目の先まで酸性を届かせるには、炭酸水素を使い切るだけの酸を、先に運び込まなければなりません」

「その量は」と久米さんが訊いた。

「割れ目の水の量と、炭酸水素の量で決まります。掘削のときに採った水から見積もると、ほぼ三十リットル。足りるかどうかは、やってみないと分かりません」

最初に口を開いたのは私だった。ドリルのヒーターで割れ目の入口を温めれば、増殖を止められるのではないか。

ヴォスさんは首を横に振った。「止まるのと死ぬのは違います。四十二度を超えると増えられなくなる。細胞の膜が壊れ始めるのは、もっと高い温度です。それに、温めた水は氷を溶かして、割れ目を広げる。広がった先から、冷たい水が流れ込んでくる。こちらが温める場所は、いつも追いつかれます」

「熱源が割れ目の奥にあるなら」と鹿島さんが言った。「奥は、どうせ温まっている」

「そうです。だから、ヒーターでは奥まで届かない」

久米さんは、次の案を口にした。原子炉の熱を使うことは、できないか。

「炉の冷却水は、放射性の物質を含みます」と私は言った。「熱交換器を通した水を割れ目へ入れれば、そこで作られた物質が、この星の水に混ざる。それは、私たちが持ち込む、もう一つの汚れです」

「では、炉は使わない」

「使いません」

鹿島さんがためらいながら言った。「凍らせるのは」

「割れ目は、放っておいても狭まっています」とヴォスさんは言った。「周りの氷は、割れ目の水より冷たい。冷えると隙間の水が凍って、壁が寄ってくる。今は、潮汐の熱の揺らぎで、一日に三回だけ隙間が広がる。凍らせれば狭まったまま止まるかもしれませんが、熱が戻れば細胞は起きる。それに、百二十メートルの隙間を凍らせるだけの冷却は、この船にはありません」

「薄めるのは」

「淡水がありません。氷を溶かすにも熱が要る。それに、塩分を変えた水は、もう元の水ではなくなります」

「入口を塞ぐのは」

「割れ目の中の細胞は残ります。塞いだ瞬間から、その中で増え続ける。蓋をすれば、あとは時間が勝手に決める」

誰も、それ以上の案を出さなかった。ヴォスさんは、表の一番下の列を指で叩いた。pHの数字だった。

「酸です」とヴォスさんは言った。「ET-214は、酸性に弱い。pHが三か四まで下がると、増えるどころか壊れる。塩酸を入れても、水の中の塩化物が増えるだけで、化学の指紋はほとんど変わらない。炭酸水素の蓄えを使い切ったあとで、水は初めて酸性に保たれる。その間に、割れ目の全部を酸で満たせれば」

「入れる道具は」と久米さんが訊いた。

私はドリルの図面を呼び出した。「柄の中は空洞で、掘削液を送る管です。この管を使えば、酸を底まで送れる。問題は、そこからです」

「三百四十メートルの孔を、どう押すかだな」

「管の中の酸と、外の塩水は、同じ深さで釣り合っています。管に酸を満たすだけでは、何も動かない。割れ目の入口は孔の底とほぼ同じ深さにあり、そこへ押し出すには、割れ目の抵抗に勝つ圧力が要るんです」

私は、割れ目の幅を思い出していた。地中レーダーの反射は細い筋に見えた。実際の隙間は、おそらく一ミリにも満たない。細い隙間を流れる水の抵抗は、隙間の幅の三乗に反比例し、長さに比例する。百二十メートルを必要な量だけ数時間で通すには、今の水圧では足りない。

「それに」とヴォスさんが付け加えた。「割れ目は、冷えると狭まります。押し込める時間は、温かい時間帯の二時間ほどだけ。その間に酸を通さなければ、隙間は閉じる。発生した二酸化炭素の泡も、隙間を塞ぎます」

私は計器室で見た、一日三回の波形を思い出していた。あの揺らぎは、センサーの誤差ではなかった。熱が割れ目を開き、冷えて閉じる、その呼吸だった。この星の熱が、私たちの作業の時間を決めている。そう思うと、掘削の計画を立てたときの自分の手際が、ひどく遠く感じられた。

「押し込む圧力は」

「十五気圧ほど。計算上は、それだけの圧力があれば、三十リットルを二時間で通せます」

久米さんは黙った。計器盤の隅の、推進剤タンクの針を見たのだと思う。

「その圧力を出せるのは」

「上昇機の推進剤の送液ポンプだけです」と私は言った。「推進剤を燃焼室へ送るためのポンプです。手押しでは、十五気圧は出ない。ドリルの電力では、ポンプを回す余裕がない。ポンプを回すには、推進剤を燃やして駆動に使う。送り切るまで回せば、残りは赤線の下になります。上昇には、もう足りない」

鹿島さんが、ゆっくり息を吐いた。「使えば、帰れない」

「はい」

「それは、ここで決めることです」とヴォスさんが言った。その声は平らだった。「戻る手段がまだ残っている。だからこそ、戻る手段を取っておくために、この水を放置するかどうかが問われている。救助は六年以上先です。誰も、この水を止めてくれない」

「確認はしたい」と久米さんは言った。「ほかに、推進剤を使わずに送る方法は、本当にないのか」

「ありません」と私は言った。「調べ尽くしました」

久米さんは目を閉じた。しばらくして、ゆっくり言った。「篠原さん」

私は顔を上げた。

「あの掘削三日目の滅菌の欄は、君一人の責任ではない。この船の滅菌を確認するのは、船長の仕事だった。私は作業表に署名した。その署名は、確認していなかったという意味でもある」

「でも、欄を空白のまま、私は接合部を離れました」

「それを、今ここで誰かの責任にする時間はない」

そのとき、ヴォスさんが口を開いた。「いいえ。あの日、篠原さんを呼んだのは私です。記録を後回しにさせたのは、私の判断です」

部屋は、しばらく静かだった。

「我々は四人だ」と久米さんは言った。「帰らない判断も、四人でする。一人で残すという考えは、私はしない」

「全員残るんですか」と鹿島さんが訊いた。

「上がれないなら、残るしかない。ポンプが止まれば、誰かが手で直す。酸の濃さは数時間ごとに測って、足りなければ注ぎ足す。割れ目が広がれば、目標の数字も変わる」

鹿島さんは頷いた。「寒さと、酸の蒸気と、睡眠。三週間が限界だと思います。交代は、二人ずつで」

注入は明日の朝九時。次の温かい時間帯に合わせる。それがヴォスさんの提案だった。私は計算表を閉じ、通信の下書きを開いた。冒頭には、水位の低下と割れ目の長さが並んでいる。その下に、今決めた手段を書き加えた。

塩酸の量と、注入の時刻。推進剤を送液に使うこと。上昇に必要な量は残らないこと。四人全員が、割れ目の水が止まるまで残ること。

書き終えたとき、窓の外の白い地平線は、もう鉛色の空と区別がつかなくなっていた。私はその景色を一度だけ見て、それから、送信の欄ではなく、注入の計画の欄へ視線を戻した。

# 追記台帳
- 注入に必要な圧力：約十五気圧（割れ目の流れの抵抗と、冷えて閉じる氷の力に勝つために必要）
- 割れ目の幅：一ミリメートル未満と推定。流れの抵抗は幅の三乗に反比例する
- 温かい時間帯：一日三回の揺らぎのたびに約二時間、割れ目が開く。その間に注入を終えなければ閉じる
- 割れ目の凍結：割れ目の水は周囲の氷より温かく、冷えると凍って壁が狭まる
- 管と塩水の釣り合い：管の酸と孔の塩水は同じ深さで釣り合うため、管に満たすだけでは押し出せない
- 炭酸水素と酸：割れ目の水を中和するのに必要な塩酸は約三十リットル（推定）。中和で生じる二酸化炭素の泡が隙間を塞ぐおそれがある
- 熱源：割れ目の奥で熱が出ており、割れ目の入口を外から温めても奥は追いつかれる
- 注入の時刻：翌朝九時。次の温かい時間帯に合わせる
- 帰還不能の理由：推進剤を送液ポンプの駆動に使い切るため、上昇に必要な量が残らない



# 改稿メモ
- 帰還不能の理由を作り直した。管と外の水が同じ深さで釣り合うため、管だけでは酸は動かないことを明記し、割れ目の流れの抵抗（幅の三乗に反比例する法則）と、冷えて閉じる氷の力に勝つ圧力が必要だという理由にした。その圧力を出せるのが推進剤のポンプだけで、駆動に推進剤を使い切るため、上昇できなくなる。
- 惑星の環境を手段に組み込んだ。炭酸水素による中和で酸が消費されること、潮汐の熱による一日三回の割れ目の開閉、冷えると隙間が閉じる氷の挙動、中和で生じる二酸化炭素の泡が隙間を塞ぐ点を、注入の時刻と量の根拠にした。
- 「戻れないことは、もう決まっていた」を削除した。ヴォスの台詞を、まだ戻る手段が残っている中で、帰還を捨てるかどうかが問われているという倫理の問題に書き直した。
- 直さなかった点：ヒーター・原子炉・凍結・希釈・封鎖の各案の却下理由は、前版の骨組みを保った。ただし、各案に惑星の環境（熱の揺らぎ、氷の凍結）の理由を一言ずつ加えた。
- 塩酸の注入、推進剤の残量、通信の文面の骨格は、後の第5章と矛盾しないように保った。
