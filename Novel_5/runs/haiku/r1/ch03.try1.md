# 第3章　亀裂

翌朝の計器室の表示は、前日と違う数字を出していた。掘削孔の底に据えた圧力変換器の値が、一晩で十六パスカル下がっている。掘削を止めてからずっと一定だった数字が、動いていた。

この星の重力は地球の七分の一ほどしかない。塩水の密度は一立方センチあたり一・二グラムで、水柱が一メートル高くなるごとに底にかかる圧力は千六百パスカル余り増える。十六パスカルの低下は、水位にすればおよそ一センチに当たる。

私は記録を一時間ごとに遡った。低下は夜半から始まっている。十時間ほどかけて、ゆっくり、一定の速さで下がっていた。一時間に一ミリ。小さな数字だが、止まってはいなかった。

「水位が下がっている」と私は言った。

ちょうど食堂から戻ってきた久米さんが、画面を覗き込んだ。鹿島さんも後ろに立った。ヴォスさんはまだ培養室から出てこない。

「どのくらいだ」

「孔の中で、およそ一センチです。ドリルを引き抜いたあとの空間に、塩水が戻るはずなんです。その戻りが足りない」

「水が漏れているということか」

「まだ分かりません。ただ、孔の底から、水が別の場所へ流れている可能性があります」

私は、整備区画から持ってきた地中レーダーの走査記録を呼び出した。着陸船の下に据えた小さな機械で、氷の中の層の境目や空洞を音で探る装置だ。掘削の前に一度だけ使った。その時は、氷が整然と層を重ねているように見えた。

今、画面の中で、掘削孔の底から斜めに伸びる線が見えた。明るい筋が、孔の底を起点として氷の中を下へ、そして横へと這っている。線は、思っていたより長かった。孔の底から、およそ百二十メートル先まで続いている。先端は、孔の底よりも四十メートルほど深い。

「亀裂だ」と久米さんが言った。

「はい。氷が割れています。割れた隙間に、水が入り込んでいる」

鹿島さんが、画面の端を指で差した。「ここ。この明るいところは、水があるということ？」

「そうだと思います。ただ、レーダーは水そのものを見分けられない。隙間の反射が強いだけです」

私は説明しながら、自分の声が平らになっていくのを感じた。機械の異常を報告するときは、怒りも恐れも数字の横に置いておかなければならない。それが機関士の仕事だった。

「ヴォスさんを呼んできます」と鹿島さんが言った。

培養室の扉が開き、ヴォスさんが顔を出した。目の下の影は、昨日より濃くなっていた。レーダーの画面を見て、彼女は一度、深く息を吸った。

「割れ目の先に、水が入っている。孔の水位が下がっているのは、水がそこへ流れているから」

「そうだと思う」と久米さんが言った。

「流れるのは、どうして」

ヴォスさんの問いに、私が答えた。「掘削のあいだ、孔の中の水は押されていました。掘削が止まったあと、圧力が変わって、氷が割れたのかもしれません。掘削で温められた氷が冷えるとき、割れ目が広がることはあります」

「そして、割れ目が広がったところに、私たちの孔の中の水が」

ヴォスさんは、そこで言葉を切った。その続きは、全員が分かっていた。

孔の中の水は、ET-214の増えている水と同じ水だった。

「割れ目の水は、採れませんか」と鹿島さんが訊いた。

「採れません」と私は言った。「割れ目へは、今の孔の底からしか入れない。その先の水を採るには、もう一本孔を開けて、新しい水を割れ目へ押し込むことになる」

「押し込まなくても、サンプルを採る方法は」

「割れ目の先は、孔の底より深い氷の中です。着陸船の採水管では届きません」

誰も、それ以上の案を出せなかった。私たちの道具は、ここまでのことしか想定していなかった。

久米さんは、窓の外へ視線を向けた。白い氷の上に、薄い風が筋を引いている。

「通信を送る」と久米さんは言った。「今すぐに」

通信は、地球との間を往復する細い糸のようなものだった。こちらから送った信号が地球に届くまで、片道で三年と二か月かかる。返事がもう一度こちらに届くまでには、さらに同じだけの時間が要る。

惑星保護の規程には、異常を見つけたら直ちに報告し、指示を仰ぐことという一文がある。その一文を、地球の誰かが読むのは、六年以上あとになる。

「指示を待っている間に、水は広がる」と鹿島さんが言った。

「ええ。だから、報告は送る。指示は、待てない」久米さんは、画面に映る割れ目の線を見つめたまま言った。「ここにいる四人で、判断するしかない」

私たちは四人しかいない。判断を預ける相手は、遠い星のどこにもいなかった。

ヴォスさんは、ふいに立ち上がった。培養室へ戻るのかと思ったが、彼女は計器室の隅の端末に向かい、孔の水位と温度を並べて表示させた。

「温度の揺らぎを見て」

掘削孔の温度の記録がグラフになっている。一日に三回、わずかに温度が上がる時刻があった。私が以前、ただのセンサーの揺らぎだと思って見過ごしていた波形だ。

「これは揺らぎではない。割れ目に、暖かい水が流れている。ほんの少し」とヴォスさんは言った。「どこかで、熱が出ている。それが氷を溶かして、水を動かしている」

私は、掘削の前に読んだ計画書の中の、潮汐による加熱という言葉を思い出した。この星の氷殻の内側で、重力が絶えず揺さぶり、熱を生む。その熱がどこにあるのかは、まだ誰も知らなかった。

「そして、暖かい水の中では、ET-214は速く増える」ヴォスさんは、冷たく言った。「割れ目の水は、温度が上がっている。ほんの一、二度でも、増え方は変わる。割れ目の先の水は、今の孔の中より速く増えている可能性が高い」

「計算は、どのくらい確かなんだ」と久米さんが訊いた。

「確かではありません。どれも仮定の上に立っています。でも、仮定を外しても、方向は同じです。広がっている」

誰も反論しなかった。反論するための材料を、誰も持っていなかった。

私は、掘削三日目の夕方の、空白の欄を思い出していた。紫外線を当てた覚えがある。ヴォスさんに呼ばれて、あとで書くと言った。その「あとで」が、本当に来たのかどうか。

「篠原さん」と久米さんが言った。「その顔は、まだ何か隠している顔だな」

私は首を振った。「隠してはいません。ただ、あの滅菌の欄のことを考えていました。私が書いていれば、もっと早く分かっていたかもしれない」

「考えても、欄は埋まらない」

「分かっています」

「それは、今ここで決めることではない」と久米さんは言った。その声は穏やかだったが、断ち切るような響きがあった。「今、決めるべきことは、どこまで広がっているかを知ることと、その広がりを止められるかどうかだ」

「止められるんですか」と鹿島さんが小さく訊いた。

久米さんは答えなかった。窓の外の白い地平線が、鉛色の空に溶けていた。

その夜、私は機関室の床に座り込んで、孔の水位の記録を見続けた。数字は、ゆっくりと下がり続けていた。一時間に一ミリメートル。十時間で一センチ。

私は、掘削三日目の夕方のことを、もう一度思い出そうとした。ドリルの表面に紫外線を当てたときの、ランプの青白い光。ヴォスさんの声。振り向いたときの、接合部の金属の冷たさ。

どれも、鮮明だった。そして、どれも、記録の欄とはつながっていなかった。

計器室の灯りの下で、私は通信の文面を書き始めた。冒頭は、事実だけを並べると決めた。孔の水位の低下、割れ目の長さ、温度の揺らぎ。そして、滅菌の記録が欠けていること。

書き終えたとき、私はその最後の一行を消せなかった。消さずに、そのまま送信のボタンの上に指を置いた。指先が、ひどく重かった。

# 追記台帳
- 表面重力：地球の約七分の一（約0.14G）。水柱の圧力は、塩水一メートルあたり約千六百パスカル
- 塩水の密度：一立方センチあたり一・二グラム
- 水位と圧力の関係：孔の中の水位低下は、夜半から十時間で約一センチ（一時間に約一ミリ）。圧力変換器の低下は十六パスカル
- 割れ目の形：孔の底（深度341メートル）を入口として、斜め下へ向かい、先端は約百二十メートル先。先端は孔の底より約四十メートル深い



# 改稿メモ
- 水位の数値：「一晩で約十二センチ」を「十時間で約一センチ（一時間に約一ミリ）」にそろえた。
- 水圧と水位の釣り合い：重力を地球の約七分の一、塩水の密度を一・二と定めた。これにより、十六パスカルの低下が一センチの水位低下と釣り合う。
- 割れ目の深さ：「割れ目の先は三百メートル」を削除し、孔の底から斜め下へ伸びて先端は孔の底より約四十メートル深いと改めた。孔の深さ（341メートル）と矛盾しない。
- 第4章への注意：第4章の「割れ目の入口は、底から百二十メートル先」は、本章の決定（入口は孔の底、先端が百二十メートル先）と食い違う。第4章の改稿時に合わせる必要がある。
- 直さなかった部分：乗員の会話、掘削三日目の記憶、通信の文面の構成は、指摘の範囲外のため残した。
