# 第3章　亀裂

汚染だとわかった日の午後、ミハイルが作業区画の扉を叩いた。

「遼、見てほしいものがある」

整備記録を洗い直すついでに、掘削孔のデータも開いてみたのだという。ドリルを引き上げたあと、私たちは孔に細い計測索を三本垂らしておいた。水位と温度と圧力を、深さごとに測り続ける線だ。塩水がどこまで上がり、どれくらいで凍るのかを調べるつもりだった。

「最初はこうだった」

ミハイルが画面のグラフを指でなぞった。塩水は孔を駆け上がり、地表から六十メートルほど下で止まっていた。氷より重い塩水が、まわりの氷の重さに押し上げられて釣り合う高さだ。そこから上のほうから順に、ゆっくり凍っていくはずだった。

「ところが、六日前からこうだ」

水位が落ちていた。一晩で百五十メートル近く下がって、地表から二百十メートルの深さで止まっている。そこから先は、上がったり下がったりを繰り返していた。

「計器の故障じゃないのか」と私は言った。

「三本とも同じ動きをしてる」

私は波の間隔を測った。山から次の山まで、およそ五日と七時間。

「エリダの公転周期だ」

口に出したとたん、背中が冷たくなった。

この星は楕円の軌道を一周するたびに、主星の重力に引き伸ばされ、また縮む。その揺れが熱を生み、南稜の断層を開いたり閉じたりしている。孔の水位が公転と同じ間隔で上下しているなら、理由は一つしか考えられない。

「二百十メートルのところで、孔が亀裂とつながったんだ。亀裂が開くと塩水を吸い込み、閉じると押し戻す。ポンプみたいに」

ミハイルは黙って頷いた。同じ答えにたどり着いていたから、私のところへ来たのだろう。

「俺のドリルのせいかもしれない」と彼は言った。「熱で溶かしながら掘るから、孔のまわりの氷は一度ゆるむ。もともと閉じていた古い割れ目が、そこで口を開けたのかもしれない」

「それは、誰が掘っても同じだ」

「わかってる。言っておきたかっただけだ」

その夜、四人で船外に出た。地中レーダーを積んだ橇を引き、孔を中心に格子を描くように氷原を歩いた。夜でも、主星の赤い光が地平線の近くに低く残っている。氷原は暗い錆色に沈み、橇の跡だけが白く浮かんだ。氷の中に水があれば、電波はそこで強く跳ね返る。

画面に、明るい筋が現れた。孔から東西へ、断層に沿って細く伸びている。深さは二百十メートル。東へ約二百五十メートル、西へ百八十メートル。

「着陸前の探査では、こんな筋はなかった」と船長が言った。

「なかったか、あっても乾いていたか、です」と私は答えた。「今は水が入っている」

「どれくらいの速さで伸びているの」

私は頭の中で計算した。

「水位が落ち始めてから六日です。東へ二百五十メートルなら、一日に四十メートルほど。ただ、開くたびに押し込まれるので、速さは一定ではありません」

「この筋の先には何がある」

「軌道からの探査で、東へ約三キロの地点に、断層が氷殻の底まで抜けている場所が見つかっています。今の速さなら、二か月半で届く」

二か月半。往復六年の通信の、二十分の一にも満たない時間だった。ヘルメットの中で、自分の呼吸がやけにうるさく聞こえた。

居住区に戻ると、私は状況を順に並べた。並べなければ、考えることができなかった。

「孔の底の塩水は、思っていたより動いていません」

観測器の流速の記録を見せた。三百七十九メートルの底では、水の流れがほとんどゼロだった。

「南稜の下では、氷殻の底がくぼんでいます。くぼみの底の水はまわりより冷たくて塩が濃いので、重い。重い水は下に溜まって、外の流れと混ざりにくい。湖の底の水がよどむのと同じです。ドリルが落とした菌は、まだその溜まりの中にいる可能性が高い。そこだけなら、局所の汚染で済みます」

「そこだけなら、ね」とアニカが言った。

「亀裂は違う。断層に沿って何キロも続いていて、ところどころで底まで抜けている。その先の海には、潮汐でかき回される流れがある」

「菌が亀裂の中で生きていられるのか」とミハイルが訊いた。「二百メートルの深さなら、もっと冷たいだろう」

「零下十二度くらいだと思う。塩水の一部は凍る。でも凍るのは水だけで、塩は残った液に濃縮される。塩分は八パーセントから、十五パーセント近くまで上がるはずだ」

私はそこで言葉を切った。資料の数字が頭に浮かんでいた。

「あの菌は零下十五度でも増える。塩分は十五パーセントまで耐える。亀裂の中は、あの菌が耐えられる限界の、ちょうど内側なんだ」

誰も何も言わなかった。

「有機物がなければ増えないんでしょう」と、アニカがようやく言った。

「増えない。でも死なない。眠ったまま運ばれて、どこかで餌に出会えば、そこで増える。この星の海に何があるのか、私たちはまだ何も知らない。知らないということは、どこにも餌がないとは言えないということだ」

もし餌になるものがあるとしたら、それはこの星が何億年もかけて作ってきた化学そのものだ。誰も名前をつけていない分子。生命になる途中だったかもしれない何か。それを、地球の菌が先に食べてしまう。

それだけではない。この菌がエリダの海に広がれば、これから誰がどれほど慎重にこの星を調べても、見つかった生き物が本当のエリダの生命なのか、私たちが落とした菌の子孫なのか、区別がつかなくなる。何百年もかけて変わっていけば、遺伝子を読んでも見分けられない日が来るかもしれない。この星に投げかけられるはずだった問いを、私たちが答えの出ない問いに変えてしまう。

「地球に知らせる」

船長が言った。

通信機の前に四人が集まった。送信文の下書きには一時間かかった。遺伝子の照合結果、滅菌記録の欠落、リングの溝の膜、孔の水位、レーダーの画像。最後に、船長が一行を足した。本隊は南稜にて状況を監視中、以後の判断は現地で行う。

送信の操作をする前に、ミハイルが手を止めた。

「届くのは三年後だ」

「わかってる」

「向こうが会議を開いて、専門家を集めて、何か決めて送り返してくる。それがここに届くのは、さらに三年後だ。その間も、亀裂は公転のたびに開いて閉じる。五日に一回。六年なら四百回以上だ」

責める口調ではなかった。計算を読み上げているだけだった。

軌道を回る母船には誰も乗っていない。私たちを地球へ運ぶための、自動の船だ。地球から救助を出すにしても、何十年もかかる。この星の上で判断を下せる人間は、この部屋の四人しかいなかった。

船長は送信した。それから、送信済みの表示をしばらく見つめていた。

「これで記録は残る。でも、助けは来ない」

その一言で何かが切れたように、ミハイルが拳でテーブルを叩いた。

「施設の作業員がリングを替えて、滅菌の予約だけ入れて、済みの印をつけた。俺たちは封を開けることすら許されなかった。それで、これは誰のせいなんだ」

「私が印を確認した」とアニカが言った。小さな声だった。「確認したと言って、署名したのは私」

「印しかなかったんだ。ほかに何を確認しろって言うんだ」

「でも、署名した」

「掘る場所を選んだのは私だ」と私は言った。

二人がこちらを見た。

「南稜を推したのは私だ。氷が薄くて、熱があって、生き物がいるならここだと言った。熱があるということは、断層が動いているということだ。亀裂があることも、それが潮汐で開くことも、私は知っていた。知っていて、そこに穴を開けた」

言いながら、それが事実だとわかっていた。生き物がいそうな場所は、生き物を持ち込んだときにいちばん広がりやすい場所でもある。惑星保護の講義の、最初の日に習うことだ。

「やめなさい」

船長の声は大きくなかった。それでも、三人とも口を閉じた。

「誰がどこで間違えたかは、記録に全部書いた。施設のことも、アニカの署名も、遼の選んだ場所も、それを私が承認したことも。裁くのは、六年後の地球の人たち。私たちじゃない」

彼女は端末を四人の真ん中に置いた。レーダーの画像の中で、明るい筋が孔から東西へ伸びていた。

「でも、ここにいるのは私たち。この筋がこれからどう伸びるかを見ていられるのも、私たちだけ」

アニカが顔を上げた。目は赤かったが、もう泣いてはいなかった。ミハイルは長く息を吐いて、拳をほどいた。

「次に開くのは、いつだ」

私は水位の記録を見た。

「三十一時間後」

その数字が、それから私たちが持つ時間の単位になった。アニカが黙って全員の脈を測った。誰の脈も、少しずつ速かった。

その夜も、私は眠れなかった。培養器の前に座って、七番の瓶を見ていた。中で、菌は今も分裂を続けている。この菌に悪意などない。与えられた場所で、与えられた条件のもとで、ただ生きようとしているだけだ。

それを運んできたのは私たちで、止められるのも、私たちしかいなかった。

# 追記台帳
- 孔内観測器：掘削孔に計測索を3本残置（水位・温度・圧力・流速を深さごとに測る）
- 孔内の水位：塩水は当初、地表から約60m下まで上昇。章の時点の6日前に一晩で地表下約210mまで低下し、以後は公転周期で上下している
- エリダの公転周期：約5日7時間（潮汐で断層が開閉する周期でもある）
- 亀裂：深さ約210mで掘削孔とつながった断層沿いの割れ目。ドリルの熱で古い割れ目が開いた可能性がある。開くと塩水を吸い込み、閉じると押し戻す
- 亀裂の広がり（地中レーダー）：孔から東へ約250m、西へ約180m。1日に約40m伸びるが、速さは一定ではない。着陸前の探査では確認されていなかった
- 亀裂の行き先：東へ約3kmの地点で断層が氷殻の底まで抜けている（軌道からの探査）。今の速さなら約2か月半で到達し、外の海の流れに乗る
- 孔の底の状態：南稜の下は氷殻の底がくぼみ、冷たく塩分の濃い重い塩水が溜まってほぼ流れがない。孔の底に落ちた菌は今のところこの溜まりの中にいる可能性が高い
- 亀裂内の環境：約零下12度。一部が凍って塩が濃縮され、塩分は15%近くまで上がる（菌が耐えられる限界の内側）
- 汚染の二重の害（遼の認識）：この星固有の化学を菌が食べるおそれと、今後の生命探査で本物と汚染の区別がつかなくなるおそれ
- 母船：軌道上にいる無人の自動船。地球から救助を出すにも何十年もかかる
- 地球への報告：汚染の証拠一式と「本隊は南稜にて状況を監視中、以後の判断は現地で行う」を送信済み（第3章）
- 責任の所在：ミハイルは施設を責め、アニカは自分の署名を責め、遼は南稜を推した自分を責める。船長は全員分の経緯を記録に書き、裁くのは地球に任せた
- 時間の単位：次に亀裂が開くまで31時間（章の終わりの時点）
