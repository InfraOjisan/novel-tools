## 3. Aion の仕上げについて
- よかった点：季節の匂い・音・温度を一文ずつ足す、という依頼を守り、筋や台詞には一切手を出さなかった。第2章（夏）は「日焼け止めと潮」「蚊取り線香」「線香花火の火薬」など、季節の手ざわりがいちばん濃くなった。
- 癖：第1章で「乾いた」を8回使った。「桜の明かり」「乾きかけた静電気」など意味が通りにくい比喩、「拂う」（旧字）「苦っぽい」などの誤字が少し入る。→ `prompts/polish.md` に「同じ形容を一章で三回以上使わない」を追加済み（Novel_base にも反映）。

## 4. 講評（Claude 自身の原稿として）
- 狙いどおりに効いているところ：一枚目と二十四枚目の「いま撮った？」「撮ってない」の反復。第4章の食卓で、父・姉・妹の三人が全員知っていながら「北海道は雪がすごい」と話す場面。プリクラの『ずっといっしょ』→『東京デビュー／いってらっしゃい』→『知ってたよ／こっちも』の三段変化。
- 弱いところ：各章が目標7,000字に対して約6,000字と短め（要件20,000〜50,000字の範囲内）。とくに第4章は父の来訪までが駆け足。父と母が直接言葉を交わす場面がない（意図的だが、読者によっては物足りない）。

## 5. 次の作品に向けて（Novel_base に反映した改良）
- `tools/inbox_llm.py`：作者が API で呼べない（Claude・人間）場合の受け箱。パケットと答えの組がすべて `work/` に残る。
- `novelctl.py`：`polish` 工程（台詞数・場面転換数・最後の一文・字数比の機械検査つき）、`AWAITING_AUTHOR`、LEDGER の必須行を `ledger_fields` で変更可能に。
- `call_llm.py`：`.env` を親フォルダ（`Novel/.env`）からも読む。
- `make_epub.py`：画像の実寸で表紙・口絵を表示、題名用の書体の埋め込み（`publish.title_font`）。
- 注意：このセッションの作業用 Linux からは、切り離したプロセスが残らないため、Aion 工程は Mac 側（Desktop Commander）で実行した。Hermes から回す場合は従来どおり `start polish` でよい。
