# やること
- 上の「BRIEF」をすべて読み、その要件を満たす物語を**あなた自身の発想で**設計してください。
- 「CANONテンプレート」の「（記入）」をすべて具体的な内容に置き換え、CANON全体を出力してください。
- 伏線スロットの中身と各章での見せ方は、配置表（BRIEF 4-2）の章番号どおりにしてください。
- 章カードは第1章〜第5章の5枚すべて。`<!-- CARD:nn -->` と `<!-- /CARD:nn -->` の目印はそのまま残してください。

# 設計の順番
1. 期限（住まいが終わる日）と、高卒就職の日程・規則、お金、年齢の節目
2. 父と母の不在の理由（悪意ではなく弱さと事情）と、家族の年表
3. 姉の嘘と妹の嘘（互いのためにつかれ、互いを自由にし、二人を引き離す）
4. 結末：それぞれの行き先と「血のつながった他人になる」具体的な形
5. 残りのスロット（C1・M1・M2・P1）
6. 不変条件、文体、章カード
